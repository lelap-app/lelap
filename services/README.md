# services

Small Hono services that run on Cloudflare Workers and, for self-hosters, in Docker. Planned:

- `catalog`: the first-party catalog add-on (Open Library, Audnexus, Podcast Index).
- `proxy`: RSS feeds and cover images for the web app. Never audio.
- `sync`: encrypted sync blobs and oplogs.
- `updates`: expo-updates manifests and `latest.json` for the APK updater.

See [`docs/brief.md`](../docs/brief.md).
