# M158 Folders as podcasts 2

What [M157](m157.md) left for a book shown as a podcast, and the fixes from its review. The rest
is planned in [M160](m160.md).

## What shipped

- **The service skips and marks** (`modules/audio`, `FolderEpisodes.kt`): the book it loads
  carries each file's played mark and where it was left (`played`, `leftAtMs`), and whether it is
  shown as a podcast (`skipsPlayed`) or keeps marks at all (`marksFiles`). Going on by itself
  into a played episode, it seeks to the next one not played, also with the app closed; each file
  it plays to its end goes into a log the app folds before the journal's places
  (`takePlayedFiles`, `markFilesPlayed` in `packages/core/src/library/folderPodcast.ts`). On
  Android the app no longer skips by itself; the web still does. The show page, Show as
  podcast/book and Mark as finished hand the loaded book its new marks (`updateEpisodeMarks`).
- **One episode in Up Next**: Play next and Add to Up next on an episode of the show page queue
  that file (`up_next.file_location`, migration `0035`, synced by location, name and count). It
  plays alone: the book's files up to it (`alone`), ending and handing over with it; the ended
  file comes with the finished record, so only that episode is marked. A book is queued once, so
  a second episode of it takes the first one's place.
- **Swipe to mark**: a swipe to the left marks an episode played or not, with Undo, which puts
  the mark and the place back (`episodesBefore`, `undoEpisodes`); TalkBack has it as an action.
  The swipe is shared with the Library's rows (`RowSwipe.tsx`).
- **The Library row** of a book shown as a podcast says how many episodes are left, and its bar
  is the share played (`LibraryBook.episodes`, `bookFraction`).
- **Review fixes from M157**: a place from the journal or a server marks the file it left only
  near its end, like the app's; places from sync mark the files passed in book view
  (`noteFileChange` with `'sync'`, without a newer entry time); synced marks match by location,
  then file name, and by index only when both devices hold as many files; This is a podcast…
  carries each episode's mark and place for a book shown as a podcast (`carryFolderPlace`); and
  after `startEpisode` the app saves no report of the old place until the player is at the new
  one (`movingTo` in `apps/app/src/player.tsx`).
