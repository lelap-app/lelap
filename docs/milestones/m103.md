# M103 Podcasts 5

What [M88](m88.md) left out, because each needs a bigger change to how an episode's file is kept.

- **Choosing among alternate enclosures.** Today an episode plays its audio `<enclosure>`, or the
  first audio `podcast:alternateEnclosure` when it has none (`alternateAudioOf` in
  `packages/core/src/podcasts/rss.ts`, M75); the other alternates are not stored. Keep every audio
  alternate with its bitrate, size and title, and pick one: a smaller file on mobile data (the
  app has `expo-network`), or the listener's choice per show. The episode's book is keyed by its
  file's address, so switching files must keep the place, the download and what syncs.
- **Checking `podcast:integrity`.** An alternate may carry an SRI hash (`sha256-…`) or a PGP
  signature. Check a downloaded file's hash against it in the download module (Kotlin, streaming,
  so a 100 MB file is never read into memory) and say so when it doesn't match. A stream can't be
  checked.
- **Chapter images on the lock screen and in the car.** The player shows a chapters file's
  pictures (M88); the media session still shows the episode's cover. That needs the playback
  service to swap the artwork by position.
