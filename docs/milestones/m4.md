# M4 Downloads

A WorkManager download service in `modules/download` with Wi-Fi and charging rules, cover and
metadata snapshots so downloads play offline, and a storage overview in Settings → Downloads and
storage. Design:
[`superpowers/specs/2026-11-16-m4-downloads-design.md`](../superpowers/specs/2026-11-16-m4-downloads-design.md).
On Android 12 and later, a download without the battery exemption runs as a plain job of about
ten minutes per run and resumes; Android 15 limits `dataSync` work to six hours a day.

Done when a book downloads overnight with the screen off and plays in airplane mode.

## Open checks

- [ ] (adb) First download on a LibriVox item: Android 17 asks for notifications, then Lelap asks for
      the battery exemption; allow both.
- [ ] (adb) Progress shows in Settings → Downloads and storage, and in the notification with a progress
      bar and Cancel (the item page passed on 2026-11-17).
- [ ] (adb) Wi-Fi off mid-download (`svc wifi disable`): “Waiting for Wi-Fi”, then it resumes from the
      same byte.
- [ ] (adb) “Only while charging” with `dumpsys battery unplug`: the download waits, then starts after
      `dumpsys battery reset`.
- [ ] (adb) Swipe the app away mid-download: the notification keeps going; reopening shows the
      progress.
- [ ] (adb) Remove download while it plays: it continues from the stream and the storage overview frees
      the space.
- [ ] (adb) Remove from library on a downloaded book deletes its files
      (`adb shell run-as app.lelap ls files/`).

- [ ] (you) A long book overnight on Wi-Fi and a charger, screen off: Downloaded in the morning; once
      with and once without the battery exemption.
