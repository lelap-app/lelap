# M119 Lists 3

What [M112](m112.md) left out when lists became something to play through.

- **Lists in Android Auto:** a Lists shelf in the car's browse tree, so a list can be started in the
  car with the app closed. The service would follow the list itself and tell the app, as it tells
  it about finished items.
- **Previous in list off the phone:** the notification, lock screen and car only have Next in list;
  the service would need the list's earlier item too.
- **The list on the widget:** a line with the list's name and what comes next, if it fits the
  widget's small sizes.
- **Lists on the web's media session:** the browser's media keys stay the skip by time; Next in
  list is only on the player screen there.
- **Lighter reads while a list plays:** the queue, the player's list line and the list screen read
  the whole library on each refresh to find the list's items; reading only those books keeps a
  large library quick.
