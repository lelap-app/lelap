# M94 Tests against real servers

From Future goals, and the lesson of Android 17: some failures only show against the real thing.

- CI service containers for a WebDAV server and MinIO (S3); the remote code runs against them
  over real HTTP.
- An emulator job that installs the release APK, opens the app, scans a folder and plays a file.
- Kept fast: only on pull requests that touch the code they cover.

Done when CI runs the remote code against real WebDAV and S3 and the app starts in an emulator.
