# M32 Audnexus

The Catalog add-on looks for an Audible ASIN among a work's Open Library audio editions and, when
it finds one, adds narrators, series, length and chapters from Audnexus to the meta
(`externalIds.asin`); it also answers `asin:` IDs with a whole meta
(`services/catalog/src/audnexus.ts`). Answers and misses are cached for a week, and a 429 stops
requests until `Retry-After` has passed. The SDK's `Meta` has an optional `series`. The app shows
the main series next to the narrators on the item page, and uses the meta's chapters for a stream
without its own only when the stream's length is within 15 seconds of the meta's `durationMs`.

Only some Open Library audio editions carry an ASIN; a source that knows ASINs should put `asin` in
`externalIds` or use `asin:` IDs.

## Open questions

- **One meta per item.** The app takes the meta of the first add-on that answers, so another
  add-on's meta with `externalIds.asin` is not enriched by the Catalog. Merging metas across
  add-ons is a separate decision.

## Open checks

- [ ] (adb) The item page for an `asin:` book shows “Series, book N · Read by …”.
- [ ] (adb) A single-file stream of the same recording as an `asin:` book gets the Audnexus chapters in
      the chapter sheet.
- [ ] (adb) A stream of another recording (its length differs) keeps its own chapters, or none.
- [ ] (adb) A downloaded book with Audnexus chapters keeps them offline.
