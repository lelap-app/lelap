# M80 App polish 2

What [M71](m71.md) left out because it is more than a small fix, or touches code that was being
changed at the time.

- Zoom: a long press on the time opens a magnified bar around the playhead (±5 minutes). A new
  gesture on the scrubber, to try on a phone. (M39)
- Suggestions deeper than the first ten of a page show the title's letter, not a cover; covers
  could come back once Home has loaded them. Needs a shared record of which covers Home's rows
  drew, and a privacy review of what that asks for. (M46)
- The Podcasts tab and podcast page draw no badges. The row already says how many episodes are
  unplayed; a “new” badge needs a count of episodes since the listener last looked, which isn't
  kept. (M49)
- Plex's “Libraries” setting takes names; a list to pick from needs the server reachable before
  sign-in finishes. (M59)
- A web save still exports and hashes the whole database in memory; on plain http the SHA-256
  runs in JavaScript, about a second per save at 10,000 books. Comparing with the last export, or
  a worker, would avoid it. (M67)
- Subsonic and Plex libraries scanned in the browser before M67 keep “001 …” as their first
  chapter until that file changes on the server. Needs a one-off read of those files again. (M67)
- The Library list reads and sorts every book again on each refresh; reading only what changed
  needs a change signal per book. (M43)
- After Match with catalog… the cover loads from the catalog's host and isn't saved on the phone;
  the link syncs, so each device needs its own copy. Needs a device-only place for the cover.
  (M56)
- Read Smart AudioBook Player bookmarks (`bookmarks.sabp.xml`) once a sample file turns up. (M34)

Done when the scrubber zooms on a long press and a matched cover shows offline.
