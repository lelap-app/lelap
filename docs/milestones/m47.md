# M47 Diagnostics

**Status:** in progress. An opt-in diagnostics log on the device (errors, player trouble from the Android service and the web player, failed downloads, scans, add-on requests and syncs) that Settings → Help → Diagnostics shows in full and shares as one text file without personal data; open checks in [m47-follow-ups.md](../m47-follow-ups.md).

Opt-in and local: a log of errors and player events kept on the device, exported from Settings
for a bug report, with add-on and sync health beside it. Nothing is collected.

## Done when

- A tester can attach one file to an issue that shows what failed, without personal data in it.
