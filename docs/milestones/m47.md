# M47 Diagnostics

An opt-in diagnostics log on the device: errors, player trouble from the Android service and the
web player, failed downloads, scans, add-on requests and syncs. Settings → Help → Diagnostics
shows the whole file and shares it as one text file without personal data: books, servers and
add-ons appear as `book#1` and the like, and times are whole hours before the file was made. The
log and the export are in `packages/core/src/diagnostics/` (tested for leaks with a database full
of secrets); the playback service keeps its own ring of 200 events (`modules/audio`).

Done when a tester can attach one file to an issue that shows what failed, without personal data
in it.
