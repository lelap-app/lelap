# M95 Self-hosting 2

- One command (`docker compose up`) with sensible defaults and a generated secret.
- A small admin page per service: version, health, sync groups and their size, no user data.
- Guides for backing up and restoring the sync database, and for running behind a reverse proxy.

Done when a fresh server runs every service from one command and shows their health.
