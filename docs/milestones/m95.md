# M95 Self-hosting 2

- **One command.** `docker compose up -d` in `docker/` builds the web app for `LELAP_DOMAIN`
  (default `localhost`), pulls or builds `catalog`, `proxy` and `sync`, and health-checks them.
  `ADMIN_TOKEN` and `CONFIG_SECRET` are made on first start into the `secrets` volume
  ([`secrets.ts`](../../docker/server/src/secrets.ts)); values in `.env` win. Every setting is in
  [`docker/.env.example`](../../docker/.env.example). `--profile https` adds Caddy with Let's
  Encrypt; `updates` moved behind `--profile updates`. Containers now stop at once on SIGTERM, and
  sync closes its database cleanly.
- **Admin page per service** ([`admin.ts`](../../docker/server/src/admin.ts)), on ports
  9787 to 9790: version, uptime, memory, health (whether the service's own port answers, plus a
  quick check of its own), which optional settings are on, cached responses; sync adds the database size and the
  100 largest groups (8-character ID prefix, size, messages, dates); updates lists published
  bundles. `/health` (ok or 503, no details, quick checks only) feeds Docker's health check. Protected by a token
  (Bearer or Basic auth, compared as SHA-256 digests) and by local addresses only; the compose file
  publishes the ports on `127.0.0.1`. The Workers have no admin page; a test checks it. Decision
  in the [brief](../brief.md#decisions).
- **Guides.** [`docker/backup.md`](../../docker/backup.md): online backup, verify and restore
  with `node sync-db.mjs` in the sync image ([`backup.ts`](../../docker/server/src/backup.ts));
  a restore refuses while sync runs, keeps the old database, and moves message numbers ahead so
  devices that synced after the backup keep receiving. Tested in Docker: backup while running,
  verify on a read-only mount, restore, refusal of a running server and of a non-database file.
  [`docker/reverse-proxy/`](../../docker/reverse-proxy/README.md): Caddy, nginx and Traefik,
  each run in Docker in front of the services with a test certificate (all four names, a 14 MB
  push reaching sync, a 17 MB one refused).

Done when a fresh server runs every service from one command and shows their health.

      `docker compose --profile https up -d` with only `LELAP_DOMAIN` in `.env`: Let's Encrypt
      certificates arrive for the four names and `https://listen.<domain>` opens the app and plays
      a LibriVox book.
- [ ] (you) [server] On that Linux server, publish an admin port on all interfaces
      (`ADMIN_BIND=0.0.0.0`) and open it from outside over IPv4: the page answers 403 even with
      the token. Then over IPv6, if the server has it: note whether it answers 401 (the caller
      looks local, as docker/README.md says) and put `ADMIN_BIND` back.
- [ ] (you) [server] nginx with a real certbot certificate and Traefik with a real Let's Encrypt
      certificate, each in front of the services: the app syncs between two devices through them.
