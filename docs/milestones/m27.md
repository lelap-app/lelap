# M27 Add-on protocol v2

- **Versioning:** `protocol` stays `1` (the major version, breaking changes only); the optional
  `protocolVersion` is the revision, absent means 1. Revisions only add optional fields and routes,
  so older add-ons and apps keep working.
- **Configure and sign-in:** the add-on's own `/configure` page. The app opens it with
  `?return=lelap://addon` and receives `lelap://addon?manifest=…` (or the listener pastes the
  address), matches the manifest `id` and asks before adding or replacing. Books, source choices,
  hidden-add-on lists and unsent scrobbles follow the new address.
- **SDK:** `createAddon({ configure })` serves a form, seals settings into a `/{token}/` address
  prefix, checks credentials through `check` and passes `config` to handlers. `GET /health` is
  always answered.
- **App:** Settings → Add-ons shows a health dot, last response time and last error from real
  requests (in memory only), asks `/health` on open and on “Check now”, and has Configure and a
  menu per add-on. The `/addon` route handles the link on Android and the web.

The protocol reference and SDK guide on the site describe the flow.

## Open checks

- [ ] (you) Deep link from a configure page: run the template (`wrangler dev --ip 0.0.0.0`), add it, tap
      Configure, pick an order and Save. Android switches back to Lelap from the browser or Custom Tab
      on the `303` to `lelap://addon?manifest=…`, shows “Update Template?”, and the catalog follows the
      chosen order.
- [ ] (you) Cold start through the link: with the app closed, open a `lelap://addon?manifest=…` link (for
      example `adb shell am start -a android.intent.action.VIEW -d '<link>'`). The profile gate and the
      confirmation don't hide each other.
- [ ] (you) Dismissing the dialog: tap outside the “Add …?” dialog; the `/addon` screen goes back to
      Add-ons and doesn't spin forever.
- [ ] (you) Web app: Configure opens in a new tab and comes back to `/addon` when the add-on lists the web
      app's origin in `returnOrigins`; without it, the configured page shows the address to paste.
- [ ] (you) Health: turn the add-on's server off and open Settings → Add-ons: the dot turns red with “The
      add-on could not be reached”. Turn it back on and tap Check now.
- [ ] (you) Kids profile: opening the link under a kids profile shows “Ask a grown-up”.
