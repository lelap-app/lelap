# M133 Settings 2

Settings had grown to one long page of 13 headings. It is now a short list of eight groups, each
opening its own page, and each line says what is set now, such as “Night · Amber · English” or
“Wi-Fi only · 3.2 GB”. Decision: [Settings](../brief.md#decisions) in the brief.

- **The list** (`apps/app/app/settings/index.tsx`): Look and language, Listening, Sleep, Library
  and sources, Downloads and storage, People and devices, Backup and updates, Help. A line's
  summary is read again when the list comes back into view; parts with no value are left out.
  TalkBack reads the group's name with its summary. A group with nothing to show on this platform
  or for this profile has no line: Sleep on the web, and for a kids profile People and devices
  without Bluetooth, Backup and updates without self-updates, Help outside a development build.
- **The pages** (`apps/app/app/settings/*.tsx`): each setting moved as it was, with its storage
  key, per-profile scope and platform rule. `src/settings/rows.tsx` holds the page frame (Back, a
  heading, the mini player) and the shared rows; `src/settings/state.ts` the settings and the
  setter that tells the player, downloads and the rest of the app what changed.
- **Routes:** `/settings` stays the list, so Home's and the Library's gear still land there. No
  other code or link pointed into Settings. On a wide screen a page opens in the same pane.
- **Malay** for the new group names and summaries; the old headings Backup, Devices, People and
  Playback left the catalog.

For the release: the landing page's help and FAQ, the docs and the README still name the old
headings (“Settings → Backup”, “Settings → Playback”). Change them when a release ships this.
