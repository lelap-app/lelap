# M53 Storage choices

- **Download folder:** Settings → Download folder takes a folder of the listener's choice (an SD
  card or a shared folder, Android only). Books sit in `Lelap/<book>/` there, and `MoveWorker` in
  `modules/download` moves existing downloads in the background: copies are checked before a book
  points at them, and originals go only after the app has reloaded the book, so a stop at any
  point leaves every book whole in one folder. A folder that can't be reached leaves its books
  unavailable but never deletes them.
- **Server folder covers:** `cover.jpg`, `folder.jpg` or `cover.png` from WebDAV and S3 folders,
  fetched with the server's login and kept in the covers folder.
- **Atom feeds** subscribe like RSS, also from OPML (`packages/core`).
- **Exports** (library, diagnostics, OPML) open the share sheet as files through `expo-sharing`;
  the web downloads them.

Done when downloads land on the SD card when chosen, a WebDAV book shows its folder's cover, and an
Atom podcast subscribes like an RSS one.

## Open checks

- [ ] (adb) Settings → Download folder → Choose, pick a folder on the SD card: downloaded books move
      there (notification “Moving downloads”), `adb shell ls /storage/<card>/<folder>/Lelap/` lists
      them, a file manager shows them, and they play in airplane mode.
- [ ] (adb) Start a download, then choose a new folder while it runs: it finishes, then moves; nothing is
      downloaded twice.
- [ ] (adb) `adb shell am kill app.lelap` during a move of a large book, open the app: the move carries
      on, and every book plays from one of the two folders.
- [ ] (adb) Move back: the books return inside Lelap and the `Lelap` folder on the card is empty.
- [ ] (adb) Remove a download that lives in the chosen folder: its folder in `Lelap/` goes too.
- [ ] (adb) Download folder inside the library folder: a rescan adds no second copy of the downloaded
      books.
- [ ] (adb) Paste an Atom podcast feed in the Podcasts tab: it subscribes, lists its episodes and plays
      one.
- [ ] (adb) Export library, diagnostics and OPML each open the share sheet with a file
      (`lelap-library-….json`, `.txt`, `.opml`); Files saves it under that name.

- [ ] (you) A WebDAV book without an embedded cover and with `Cover.JPG` in its folder shows that cover
      after a scan, offline too; an S3 book with `folder.jpg` the same.
- [ ] (you) With books on the SD card, take the card out: they stream where they can, Settings says the
      folder can't be reached, and nothing is deleted; put it back: they play from the card again.
- [ ] (you) A book that plays while it moves keeps playing to its end from the old copy; after pausing,
      the old copy is gone (`adb shell run-as app.lelap ls no_backup/downloads/<book>/`).
