# M63 Playback fixes

Review findings in `modules/audio` and the app’s player that were left for later. Each is small; together they make places and the lock screen more exact.

- The journal’s speed goes stale after a speed change, so resuming restores the speed the book was loaded with. (M2)
- Resuming measures the pause from `savedAt`, not from the pause itself; store `pausedAt`. (M2)
- Errors from custom session commands (for example a rejected book) don’t reach JavaScript. (M2)
- `PlayerState.partTitle` shows the chapter title, which the M1 spike screen still displays as the part. (M2)
- Changing the skip interval doesn’t tell connected controllers. (M2)
- The whole playlist is written to the journal on every tick; write it once per load. (M2)
- The paused load at start-up moves `lastPlayedAt`, which shortens the next smart rewind. (M2)
- Reaching the end of a book doesn’t mark it finished. (M2)
- Removing a streamed book while it plays from its downloaded files leaves the player on deleted files until the next load. (M4)
- Resuming from headphones can still pick up another profile’s book from the journal after a profile switch. (M9)
- Chapters found from silences reach a playing book only at its next load, so the lock screen title and the end-of-chapter sleep timer keep the old list. (M45)
- A place saved inside a show’s intro is moved past the intro at the next load. (M45)
- A book ID longer than 200 characters makes a player event fail validation, so it is dropped from the diagnostics log. (M47)
- With weeks unopened, the accounting log grows (two records per 5 minutes, the oldest dropped after about 125 hours) and is re-encoded on the main thread; keep a total per book and day beside the events. (M51)
- Android backup restores `lelap_accounting` apart from the database, so record numbers could repeat; leave the file out of backups. (M51)
- A book queued in the service’s Up Next keeps its old paths after a download move, so it may stream or fail to start. (M53)

Each item above is fixed with a test where the code allows one.
