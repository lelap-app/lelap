# M67 Web app 2

What the web app lacked next to Android, built:

- **Saves write only what changed.** The database is kept in OPFS as 256 KB chunk files and a
  manifest (`packages/core/src/chunkedFile.ts`, used by `apps/app/src/db.web.ts`). A change in a
  10,000-book library (49 MB) writes one or two chunks instead of the whole file. The old single
  `lelap.db` is read once and removed. Why chunks and not a VFS: see the brief's
  [Web](../brief.md#web) section.
- **Media Session follows the chapter.** The system controls' progress bar is the chapter playing
  (the whole book without chapters, the file when durations are unknown), and dragging it seeks
  there (`mediaSpan` in `packages/core/src/library/timeline.ts`). Unloading a book clears the
  title, state and position.
- **The skip interval shows at once.** Changing it refreshes the library signal, so the list of
  shortcuts and the Player's skip buttons say the new interval without reopening.
- **Hints and actions on the web** (`apps/app/src/a11y.ts`): `accessibilityHint` becomes an
  `aria-describedby` description; a row's TalkBack action (Hide in the Library, Delete in
  Bookmarks) runs on the Delete key and is announced with `aria-keyshortcuts`. The scrubber takes
  focus and moves with the arrows (5 %), Page Up and Page Down (20 %), Home and End
  (`sliderKey` in `packages/core/src/screen.ts`).
- **Covers from servers.** WebDAV, S3, Subsonic and Plex folder covers are fetched with the
  server's login into OPFS `/covers` and shown as blob URLs (`apps/app/src/webCovers.ts`).
- **The first file of a Subsonic or Plex book keeps its title** in the browser: the bundled add-ons
  send its tags without a length, and they fill in what the browser's read lacks (`fillTags` in
  `packages/core/src/remote/addon.ts`; protocol docs updated, no version change).

Already fine: Library rows and the Continue listening card show archive.org covers on current
`main` (checked in the browser with a LibriVox book); nothing changed for it.

Left out: the Cast tool on the web, moved to [M78](m78.md).

Done when a 10,000-book library saves a change in the browser without writing the whole file.
