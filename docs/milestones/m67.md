# M67 Web app 2

What the web app still lacks next to Android.

- The web app writes its whole database (49 MB at 10,000 books) after every change; an OPFS VFS that writes only changed pages fixes it. (M43)
- Media Session’s position state is per file, not chapter or book, and is not cleared when the book is unloaded. (M44)
- The shortcut list reads the skip interval when it renders, so a change shows only the next time it opens. (M44)
- `accessibilityHint` and TalkBack actions have no web equivalent, and the scrubber can’t be moved with the keyboard. (M42)
- No folder cover for WebDAV or S3 books on the web. (M53)
- The browser keeps no covers folder, so Subsonic books show no cover there. (M58)
- In the browser, the first-file read of a Subsonic or Plex book gives only the duration, so the first chapter shows its file name. (M58)
- Library rows and the Continue listening card draw an empty tile where an archive.org cover should be. (M49)
- No Cast tool in the web app. (M26)

Done when a 10,000-book library saves a change in the browser without writing the whole file.
