# M79 Library by progress

Asked for by a listener: with many books marked, it is hard to see which ones you have already
heard. Other apps charge for this. The data is already there, so this is a new view of the Library,
not new data.

- The Library's default view shows three groups, each with its own order:
  - **In progress**, on top, by last played (`library_entries.last_played_at`).
  - **Not started**, by last added (`added_at`).
  - **Finished**, at the bottom and collapsed by default (“Finished (42)”), by last finished
    (`finished_at`).
- Title and Author stay as sorts that show one flat list, without groups.
- Hidden books (M77) stay apart, in their own view.
- Covers already carry finished and started badges in Discover and Search (“Badges on covers”), so
  a book heard and then removed from the Library is still recognisable there.
- The groups work the same for books and for the profile's own episodes in the Library, if any, and
  on the web.

Done when the Library opens in the three groups, each sorted as above, the Finished group opens and
closes and remembers it, and Title and Author still give flat lists.
