# M2 Local library

SQLite through Drizzle (`packages/core`), folder access, tags, chapters and the position journal
in `modules/library` and `modules/audio`, and the Library, Player and Settings screens in
`apps/app`. Every user-specific table has a `profile_id` from the first schema, so profiles (M9)
needed no migration. Design:
[`superpowers/specs/2026-11-16-m2-local-library-design.md`](../superpowers/specs/2026-11-16-m2-local-library-design.md).

Done when you listen to your own files for a week in airplane mode without losing your place.
