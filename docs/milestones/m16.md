# M16 Organise

Tags per book, hand-made lists and smart lists (a saved rule: status, books or episodes, length,
ready offline, tags) live in `packages/core/src/organise.ts` and sync like places do. The Library
shows lists and tags; a book's menu (long press, or the ⋯ button on the web) sets tags and adds it
to a list. Settings → Backup exports everything as one JSON file and imports it by merging
(`packages/core/src/backup.ts`): the export is the same set of changes sync sends, so where both
sides changed a row the newer change wins.

Local books are named by their path inside the chosen folder, so an import finds them only after
the same folder is chosen and scanned on the new phone. The export holds add-on addresses, which
can contain keys, so Settings says to keep the file private; server passwords are never exported.

Done when your shelves, tags and lists survive moving to a new phone through an export file.
