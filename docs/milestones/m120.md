# M120 Big screens 3

[M113](m113.md) brought the third column, dividers, foldables and dragging to a list in the rail on
the web. Left for here:

- **Drag on Android:** with a mouse or a stylus on a tablet, drag a book or an episode onto a list in
  the rail. React Native has no drag and drop of its own, so this needs a gesture library or a small
  native piece; the row's menu does it for now.
- **Drag from catalog tiles:** a tile on Home, Discover or Search isn't in the library yet; dropping
  it on a list would add it to the library first, as Play does.
- **Drop on the Library's list cards** as well as on the rail, for windows where the rail is short.
