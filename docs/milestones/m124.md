# M124 Languages 4

What [M99](m99.md) left.

- **Chapter names the listener typed are kept.** Migration `0027_chapter_names` in beta 11 also
  emptied the listener's own chapter titles that read exactly “Chapter n” or “Bab n” for their
  place, though a name there may have been typed. The migration no longer touches own chapters, so
  a phone that updates from beta 10 or earlier keeps them (the migrator goes by date, not by the
  file's contents). The brief now says a name in own chapters is never cleared.
- **What can be restored, and what can't.** On the phone itself nothing is left: the migration
  overwrote the names, and Lelap keeps no older copy. With sync on, the sync group still holds
  each list as it was sent, names and all. Once per device, after a sync,
  `restoreNamesFromGroup` in `packages/core/src/sync/engine.ts` reads the group's snapshot and log
  and `restoreOwnChapterNames` in `sync/ops.ts` gives a name back where the list here is the same
  version (same time, same starts) and the only difference is a name 0027 emptied. A list saved
  again since stays as the listener left it. The row keeps its time, so nothing is sent; each
  device restores its own. Without sync, or when the list was saved again on a phone with beta 11,
  the names are gone and have to be typed again. A name restored this way may also be one an
  earlier scan made up and the editor saved with the rest; it then shows as it was before beta 11,
  in that language, and emptying the field names it in the profile's language again.
- **A language switch renames chapters at once.** `renameChapters` in `apps/app/src/player.tsx`
  hands the loaded book its chapters again on a switch: the Android service renames the
  notification, the lock screen, the widget and Android Auto's title at the live place, and the web
  player takes the new names in place (`updateBook` in `audio.web.ts`, only when the starts are the
  same). The library refresh that follows sends Up Next and the car's shelves again with the new
  names. Screens such as the Continue card are drawn again on a switch already (keyed by language).
- **Own chapters made from found ones say “Part n”.** An own chapter copied from one found from
  silences carries `found: true` (in `StoredChapter`, kept by `cleanChapters` and sync; older
  versions drop it). A list saved before this has no mark: an untitled own chapter at the start of
  a found chapter is a part too (`getOwnChapters`). The editor's placeholder follows each row, and
  a chapter added by hand is a “Chapter”.
- **SMB and SFTP failures inside another exception get their own line.** `NetFailure` implements
  `Explained` from `modules/text`, which `Reasons.of` asks along the cause chain; downloads and
  moves use `Reasons.of` alone.
- **No internal English text left in those failures.** A download job or the list of old copies
  that can't be saved throws `NotSavedException` (“Lelap could not save to the phone’s storage.”),
  and casting to an unknown kind of receiver says “Lelap can’t cast to this kind of speaker.”
  English messages that only reach logs and error codes stay (`NetFailure`'s own message, the
  HTTP helpers').
