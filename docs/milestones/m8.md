# M8 Release pipeline

`release.yml` runs on `v*` tags: a signed APK, R2 (`lelap-downloads`, public on `dl.lelap.app`)
and GitHub Releases, `latest.json` or `beta.json`, multi-arch Docker images on
`ghcr.io/lelap-app` and build provenance. The in-app APK updater is `modules/updater`; it trusts
`latest.json` over HTTPS with the SHA-256 in it, and Android refuses an APK signed with another
key. Secrets and variables live in the `release` environment; Docker entries are in `docker/`.
Betas 3 to 5 went out through it. Over-the-air bundles came in [M18](m18.md), one APK per CPU
type in [M54](m54.md). The landing page links to the APK once `site.released` is true (see
`apps/site/AGENTS.md`).

Done when someone installs Lelap from `lelap.app` and receives an update without help.

## Setup

In the `release` environment (tags only, required reviewer):

| Name                           | Kind     | What                                                           |
| ------------------------------ | -------- | -------------------------------------------------------------- |
| `ANDROID_KEYSTORE_BASE64`      | secret   | `base64 -i release.keystore`; `CN=Lelap`, keep an offline copy |
| `ANDROID_KEYSTORE_PASSWORD`    | secret   | Keystore password                                              |
| `ANDROID_KEY_ALIAS`            | secret   | Key alias                                                      |
| `ANDROID_KEY_PASSWORD`         | secret   | Key password                                                   |
| `CLOUDFLARE_WORKERS_API_TOKEN` | secret   | Workers, D1 and R2 edit (separate from the Pages token)        |
| `CLOUDFLARE_ACCOUNT_ID`        | variable | Same as in `web`                                               |
| `DOWNLOADS_BASE`               | variable | `https://dl.lelap.app`                                         |
| `SYNC_DOMAIN`                  | variable | `sync.lelap.app`                                               |
| `LELAP_DOMAIN`                 | variable | Optional; `lelap.app` when unset                               |

Cloudflare: R2 bucket `lelap-downloads`, public on the downloads host (R2 needs a payment method
on the account), and D1 `lelap-sync` ([M7](m7.md#setup)). The `ghcr.io/lelap-app/*` packages are
public; the organisation first has to allow public packages (Settings → Packages → Package
creation → Public).
