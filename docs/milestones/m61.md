# M61 Open Library reading log

**Status:** in progress. The Open Library reading log comes with the app as an add-on inside it
(protocol revision 8): set up under Settings → Add-ons with archive.org S3 keys, which stay sealed
on the phone; starting a book puts its work on Currently reading, finishing it on Already read.
Android only. Real-account checks are in [m61-follow-ups.md](../m61-follow-ups.md).

A first-party scrobble add-on, like Hardcover's: books finished or started in Lelap are marked
“Already read” or “Currently reading” on the listener's Open Library account. Lelap already names
works by Open Library IDs, so no matching is needed. Listeners add it by its manifest URL and sign
in on its settings page.

## Done when

- Finishing a book in Lelap marks it read on Open Library within a minute.
