# M117 Themes 2

What [M108](m108.md) left out.

- **High contrast in a file:** a theme file has no `highContrast`, so saving the high contrast
  theme and opening it again gives a plain theme with the same colours: checked at 4.5:1, a 2 px
  focus ring, see-through badges. An optional `highContrast: true` that also holds the file to
  7:1 would keep it.
- **A file theme in car mode:** when car mode swaps a file's light theme for Night (or a dark one
  for Day), it uses the profile's built-in accent, which the file theme hides in Settings. Car
  mode could keep the file's accent where it passes on the swapped theme.
- **A live switch:** a new theme or accent draws the screens again under a new key, so Settings
  loses its scroll place on Android with each tap. Reading colours through a hook (or CSS
  variables for icons on the web) would let a theme change without the remount.
