# M117 Themes 2

What [M108](m108.md) left out. Decision in the [brief](../brief.md) (Themes).

- **High contrast in a file:** a theme file may carry `highContrast: true` (optional, so older
  files still read). Saving the high contrast theme writes it, and opening the file brings high
  contrast back: the 4 px focus ring, solid badges over covers, and the same look day and night in
  car mode. A file that says so is checked at 7:1 for text and 3:1 for borders when it is opened,
  and refused with the failing pairs otherwise. `ThemeFileSchema` and `parseThemeFile` in
  `packages/core/src/themes.ts`.
- **A file theme in car mode:** when car mode swaps a file's dark theme for Day (or a light one
  for Night), it keeps the file's accent: as it is when it passes every pair there, else in the
  nearest lightness of the same hue that does (a bright pink becomes a deep one on paper). Only
  when no lightness passes does the profile's accent stand in. `carTheme` in `themes.ts`; Settings
  says “A theme from a file brings its own accent, in car mode too.”
- **A live switch:** a new theme or accent no longer draws the screens again under a new key.
  Icons and other colours outside a class read `useColors()` (`apps/app/src/theme.tsx`), which
  draws each reader again in place; classes already follow the CSS variables. Settings and every
  open screen keep their scroll place. `COLORS` is gone, and `check-accessibility.mjs` fails on
  any use of it. A new language still draws the screens again.
