# M144 SDK 0.6

`@lelap/sdk` is at 0.5.0 on npm, while revisions 10 and 11 (M100, M102, M118's `choice` settings
and `settings` resource), the sealed config ID (M104), the test kit (M114) and series in the
protocol (M127) wait as changesets. Third-party add-ons can't use what isn't published, so this
is the one add-on milestone worth doing now. The app needs no add-on of ours for it.

- Run `changeset version`, read the generated changelog, and merge the version bump; `sdk.yml`
  publishes it with provenance.
- Check the protocol reference, the JSON Schema and `examples/` against revision 11, and make
  every example pass `lelap-sdk check`.

**Done when** `npm view @lelap/sdk version` shows 0.6.x and a fresh project built from the docs
alone passes `lelap-sdk check`.
