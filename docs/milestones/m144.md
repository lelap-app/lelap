# M144 SDK 0.6

`@lelap/sdk` 0.6.0 publishes revisions 10 to 13 (M100, M102, M118, M135, M136), the sealed config
ID (M104), the test kit (M114) and series (M127), which had waited as changesets, plus the
SDK-only items a third-party add-on author asked for on 2026-11-20. Merging the version bump made
`sdk.yml` publish it with provenance.

## What shipped

- **`waitUntil` in every handler's args** (`HandlerArgs` in `packages/sdk/src/addon.ts`).
  `addon.fetch(request, env, ctx)` hands it to the Workers execution context; without one the
  promise simply runs, and a rejection goes to `onError`. The catalog service and
  `services/template` pass Hono's execution context on (`contextOf` in `services/catalog/src/app.ts`).
- **Configure fields:** `link` (`href`, `text`, http or https only, checked at start) shown under a
  field, and `group`, an `<h2>` the page sorts fields under: ungrouped first, then groups in the
  order they first appear (`packages/sdk/src/config.ts`).
- **Credential helpers** in `packages/sdk/src/credentials.ts`: `fingerprint(secret)` (16 hex
  characters of SHA-256) and `log(event, fields)`, one JSON line of strings, numbers and booleans;
  anything else prints as `[dropped]`, URLs lose query, fragment and login, strings stop at 200
  characters.
- **`mockFetch(routes)`** in `@lelap/sdk/check` (`packages/sdk/src/mock.ts`): `URL` or
  `METHOD URL` routes, a trailing `*` for a prefix, the longest match wins; any other request
  fails and is listed in `unmatched`.
- **Examples:** the guide's source step logs each lookup with `log`; the guide's and the source
  sample's tests stand in for Open Library with `mockFetch`.
- **Docs:** the SDK README, `/docs/sdk/` (new sections on work after the answer and on keys in
  cache keys and logs), `/docs/checking/`, `/docs/protocol/`, `/docs/guide/` and `/docs/` now say
  0.6 instead of “the next release”. Tests in `packages/sdk/src/sdk06.test.ts`.
