# M40 First release

**Status:** in progress.

Every milestone so far is built, but Lelap has only had one beta (`v0.1.0-beta.1`, whose web
image timed out). This milestone ships it: a beta with everything in it, a second round of phone
tests through the follow-up files, fixes, and a stable `v0.1.0`.

## Steps

1. Tag `v0.1.0-beta.2` from `main`: signed APK, F-Droid APK with `SHA256SUMS`, `beta.json`,
   over-the-air bundle, five images on `ghcr.io`.
2. Install it from `dl.lelap.app` on a phone; an older beta updates itself.
3. Test round 2 ([`testing.md`](../testing.md)): the open checks in each `mN-follow-ups.md`,
   grouped by what they need (one phone, two devices, a car, speakers, a watch).
4. Fix what fails in small pull requests; tag further betas as needed.
5. Bring each milestone's status line up to date: done when its checks pass.
6. Tag `v0.1.0`; sync deploys to production; the landing page links to the APK
   (`site.released`).

## Done when

- `v0.1.0` installs from `lelap.app` and updates itself to the next release without help.
- No open check in a follow-up file is older than this milestone without a reason written next to
  it.
