# M19 Security and hardening

An audit of the services and the app, with its fixes: a controller allowlist on the playback
session, sync reset that tells other devices, the sync key and server passwords sealed with a key
held in the Android Keystore (`packages/core/src/secrets.ts`), a size check in the updater, and a
Content-Security-Policy and other headers for the web app. The findings, the reasoning and what
was fixed are in [`security-audit.md`](../security-audit.md). Idle sync groups were settled in
[M52](m52.md) (see [Decisions](../brief.md#decisions)).

## Open questions

- `WEB_ORIGIN` (finding 4): set it in the `web` environment (rate limits are already on
  Cloudflare).
- Separate Cloudflare tokens for the `web` and `release` environments (finding 11).
- Plain http on Android (finding 17): keep it off and explain why, or allow it.
- HSTS for the zone in the Cloudflare dashboard.
