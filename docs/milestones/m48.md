# M48 More languages

Catalogs are JSON files the app finds by itself (`apps/app/src/i18n/catalogs/`), checked in
`pnpm test` and CI by `apps/app/scripts/check-translations.mjs`. Translators can work in the
browser and through an issue form, without a development setup. Native Android text
(notifications, widget, Quick Settings tile, Android Auto) comes from the same catalogs through
`modules/text`, and the landing page is in Malay at `/ms/`.

Done when a third language arrives from someone outside the project and ships without code
changes beyond its catalog.

## Open checks

- [ ] (adb) Profile in Bahasa Melayu, play a book: `uiautomator dump` of the notification shows “Undur 30
      saat”, “Maju 30 saat”, “Pemasa tidur dimatikan”;
      `adb shell cmd notification list_channels app.lelap` (or the settings screen) names the player's channel “Kini dimainkan”, and after a
      download and a chapter search also “Muat turun” and “Mencari bab”. Back to English: the names
      follow without a restart.
- [ ] (adb) Malay chosen, app swiped away: the widget reads “Tiada yang dimainkan” or the book with
      “Jeda”/“Main”, the tile “Sedang dimainkan” or “Dijeda”; switch to English in the app and both
      redraw. A Malay and an English profile (for example a Malay kids profile and an English
      grown-up) switch the notification, widget and tile along when switching profiles.
- [ ] (adb) A download in Malay shows “Memuat turun” with “Batal”; finding chapters shows “Mencari bab”
      with “Henti”.

- [ ] (you) Android Auto (or the Desktop Head Unit) with a Malay profile: the shelves read “Teruskan
      mendengar”, “Dalam telefon ini”, “Podcast”, “Seterusnya”.
- [ ] (you) From a GitHub account without write access: edit `catalogs/ms.json` in the browser and
      propose it, then add a language (`catalogs/xx.json`) from `template.json`; the pull request's
      check points at the problem lines (annotations need the maintainer to approve the first run for
      a new contributor). The translation issue form shows and files with the `translation` label,
      which may need creating.
- [ ] (you) A native speaker reviews the Malay. Every line is open for review; these are the ones we were
      least sure of (English → Malay):
