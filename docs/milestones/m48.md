# M48 More languages

**Status:** in progress. Built: catalogs as JSON files the app finds by itself, a browser and
issue-form path for translators with a check in CI, native Android text through the same catalogs
(`modules/text`), and the landing page in Malay at `/ms/`. Open: the phone checks and the Malay
review in [m48-follow-ups.md](../m48-follow-ups.md).

A way for translators to contribute without a development setup, native Android text
(notifications, widget, Quick Settings tile) through the same catalogs, and the landing page in
Malay.

## Done when

- A third language arrives from someone outside the project and ships without code changes beyond
  its catalog.
