# M145 Upkeep 2

Leftovers that are each too small for a milestone of their own but make something wrong today.
Kept: only what fixes a wrong result, a rebuffer or a missing guard. Ideas that only add options
stay out.

- **Scrobble bookkeeping (M102):** mark a book as heard by an add-on when its event is delivered,
  not queued, and log a session's start with the Android `finish` itself, so a short session
  never borrows an earlier one's start.
- **Episode files (M121):** the service compares what `EpisodeFiles` would pick rather than the
  addresses sent, so re-picking a loaded episode's automatic file doesn't prepare it again.
- **Playback history (M138):** while casting, log a seek's target rather than the receiver's
  lagging position; log skips at the place the service lands on across file ends; log taps for
  the profile the player plays for; don't offer “Go back” after the notification's own Back.
- **Unknown resources (M127):** an app that meets a resource it doesn't know drops it instead of
  refusing the manifest, so later resources can join existing add-ons.
- **Hidden books (M127):** a hidden book matched only by its title no longer shows as one the
  listener lacks.
- **Add-on permission lines in Malay:** wrap the texts in `packages/core/src/addons/permissions.ts`
  in `t()` and add Malay.
- **Guards (M117, M83):** `eslint-plugin-react-hooks` in `pnpm lint`, and the accessibility
  check's gaps: errors inside a `View` or returned early, short hex and `rgba()` colours, spinners
  outside a ternary.

**Done when** each item has a test or a lint rule that fails without it, and Future goals no
longer lists them.
