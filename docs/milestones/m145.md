# M145 Upkeep 2

Leftovers that are each too small for a milestone of their own but make something wrong today.
Each has a test, or a lint rule, that fails without it.

- **Scrobble bookkeeping (M102):** a book counts as heard by an add-on once its event is delivered
  (a 2xx), not when it is queued; an event of the same item still waiting for that add-on counts
  too, since it goes out first (`sendScrobbles` in `packages/core/src/scrobble.ts`). On Android
  the finish carries the start of the session that reached the end, or none, never an earlier
  session's (`ListeningTally.finishStart` in `modules/audio`).
- **Episode files (M121):** the service compares what `EpisodeFiles` would pick, not the addresses
  sent, so re-picking a loaded episode's automatic file doesn't prepare it again
  (`PositionJournal.filesChanged`).
- **Playback history (M138):** while casting, a seek logs its target rather than the receiver's
  lagging position (`PlaybackHistory.landing`); the app logs skips where the service lands across
  file ends (`skipLanding` in `packages/core/src/library/timeline.ts`); taps are logged for the
  profile the player plays for (`playerProfileOf` in `profiles.ts`); and the player offers no
  “Go back” after the notification's own Back (`offersGoBack` in `history.ts`).
- **Unknown resources (M127):** `readManifest` (`packages/core/src/addons/manifest.ts`) drops
  resources the app doesn't know before checking the manifest, so later resources can join
  existing add-ons. A manifest with no known resource is still refused.
- **Hidden books (M127):** a hidden book matched only by its title no longer shows as one the
  listener lacks (`heldTitles` in `library/series.ts`, `seriesRows`).
- **Add-on permission lines in Malay:** `addonPermissions` takes the app's `t()`, and
  `check-translations.mjs` reads core files that take one.
- **Part transcripts (after M136):** a synced book another device already has takes the newer
  add-on reference for the same recording (`applyAddonItem` in `packages/core/src/sync/ops.ts`),
  so transcripts an add-on adds later reach it; and the transcript screen reads the database again
  when the library changes, not only when the part does.
- **Guards (M117, M83):** `react-hooks/rules-of-hooks` in `pnpm lint` (`eslint.config.mjs`); it
  found nothing. `exhaustive-deps` stays off, see Future goals. The accessibility check
  (`apps/app/scripts/check-accessibility.mjs`) now sees errors inside a `View` or fragment and
  returned early, short and eight-digit hex, `rgb()` and see-through colours, and a spinner that
  replaces a button's text in any form, and checks itself with snippets that must fail. It found
  three errors that appeared unannounced (the start screen, the Cast sheet, Discover), now fixed.
