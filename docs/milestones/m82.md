# M82 First start

Today a new listener lands in an empty Library. A short first start explains Lelap in two
screens and gets them to something playable.

- Welcome, then choose where books come from: a folder on the phone, a server, or the open
  catalogs (LibriVox and the Open Library catalog are already installed).
- Our own optional add-ons (Hardcover, gPodder) offered, never third-party ones.
- Empty states on Home, Library and Podcasts that say what to do next.
- Skippable, and never shown again once the listener has a book.

Done when a fresh install reaches a playing book in under a minute without help.
