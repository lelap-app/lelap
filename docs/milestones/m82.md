# M82 First start

A new listener no longer lands in an empty Library. Decision in the
[brief](../brief.md#decisions) (“First start”).

- **The flow** (`apps/app/app/welcome.tsx`): a welcome with Lori and two lines on what Lelap is,
  then “Where are your books?” with three choices, then “Optional add-ons”.
  - _A folder on this phone_ opens the system folder picker (the same `chooseFolder` as the
    Library) and starts the scan at once. On the web, where a browser can't open folders, it becomes _Another device with
    Lelap_, which opens Sync to join with a pairing code.
  - _A server_ opens the existing add-and-check screen; once a server is added, the flow moves on.
  - _Free books to play now_ says LibriVox and the Open Library catalog are already installed and
    ends on Home, with their rows.
  - _Optional add-ons_ offers only our own: the Open Library reading log (bundled), Hardcover and
    gPodder sync (hosted). The offers are shared with Settings → Add-ons
    (`src/components/OwnAddons.tsx`).
  - Every step has Skip; Android's Back goes to the step before. Done or Skip lands on Library
    (folder, server, sync) or Home. A kids profile picked at launch leaves the flow.
- **When it shows** (`needsFirstStart` in `packages/core/src/firstStart.ts`): asked once when the
  tabs open; only on a device with no book, folder or server, for a profile with no podcast, never
  for a kids profile, and never after it was finished or skipped (a per-profile marker in
  `settings`, not synced). An existing install never sees it.
- **Empty states:** Home shows “Nothing to continue yet” with a way to the Library while the
  device has no book; the empty Library offers the folder (Android), a server and the free books
  on Home, and tells a kids profile to ask a grown-up; Podcasts adds “Search for podcasts”.
- **TalkBack:** each step's title is a header and takes focus when the step changes (the
  browser's focus on the web); every choice is one button.
- 29 new English lines with Malay.

## Open checks

- [ ] (adb) On a fresh install (`adb shell pm clear` on the app), Lelap opens on “Welcome to
      Lelap”; Get started → “Where are your books?” lists A folder on this phone, A server and
      Free books to play now.
- [ ] (adb) In the first start, A folder on this phone → pick a folder with audiobooks → Optional
      add-ons → Done lands on Library, which scans the folder and lists its books.
- [ ] (adb) In the first start, A server → add a WebDAV or Audiobookshelf server → back on the
      flow it moves on to Optional add-ons by itself; Done lands on Library with the server's
      books.
- [ ] (adb) In the first start, Free books to play now → Done → Home; tap a LibriVox book and
      Play: it plays within a minute of the fresh start.
- [ ] (adb) Updating an install that already has books or a server to this version never shows
      the welcome; nor does restarting after Skip or Done.
- [ ] (adb) TalkBack on: each step's title is read first after Get started and after choosing a
      source; each choice reads as one button with its description; Skip and Done are reachable.
- [ ] (adb) Optional add-ons → Set up on Hardcover opens its configure page in the browser and
      Lelap adds it when the page sends you back (you land on Settings → Add-ons; Back returns to
      the flow); Open Library reading log → Set up opens its settings screen.
- [ ] (adb) In the first start, Back on Optional add-ons returns to “Where are your books?”, and
      Back there returns to the welcome; Back on the welcome closes the app.
- [ ] (adb) The first start and the new empty states in Malay (Settings → Language → Bahasa
      Melayu on a fresh profile) fit on a small phone without clipped text.
- [ ] (you) A native speaker checks the 29 new Malay lines in `apps/app/src/i18n/catalogs/ms.json`
      (“Selamat datang ke Lelap”, “Di manakah buku anda?”, “Alat tambah pilihan”, the empty
      states).
