# M14 Developer platform

`lelap.app/docs` is a developer section (`apps/site/src/pages/docs/`): overview, protocol
reference, data model samples, SDK guide, samples, hosting and a manifest builder that checks
manifests in the browser. Samples in Hono ([`services/template`](../../services/template)), plain
Node and Python, and an add-on with hard-coded seasonal catalogs, are in
[`examples/`](../../examples) and tested in CI.

Done when someone outside the project builds an add-on from the docs alone and adds it in the app.

## Open checks

- [ ] (you) Build and run the Dockerfiles of `examples/node-addon` and `examples/python-addon`; each
      container answers `/manifest.json`.
- [ ] (you) Add each sample (the Hono template, the Node, Python and seasonal catalogs samples) to the
      app on a phone by its manifest URL; its catalogs show on Home and its items open.
