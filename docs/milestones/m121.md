# M121 Podcasts 6

What [M103](m103.md) left out.

- **Integrity checks for web downloads.** The phone checks a downloaded file's `podcast:integrity`
  hash in the download module; the web app's downloads (OPFS) don't. Web Crypto only hashes a
  whole buffer, so this needs an incremental SHA-2 in JavaScript over the parts as they are
  written.
- **The smaller file with the app closed.** The app picks an episode's file when it loads it or
  starts its download. Episodes Up Next or the car start with the app closed play the file the app
  last sent, so on mobile data they may stream the larger one. The playback service would need the
  alternates and the network state to pick by itself.
- **Chapter images in the browser.** The web player's media session (`navigator.mediaSession`)
  still shows the episode's cover; it could take the chapter's picture like the phone's lock
  screen.
