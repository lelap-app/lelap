# M41 Audiobookshelf

Audiobookshelf is a library source built into the app next to WebDAV, S3 and Jellyfin
(`packages/core/src/remote/audiobookshelf.ts`, `apps/app/src/audiobookshelf.ts`). It connects with
the server address and an API key, checked with `/api/me`; Audiobookshelf 2.26 or later only (see
the Audiobookshelf login decision in [Decisions](../brief.md#decisions)). The key is sealed like
other server secrets. A refused key marks the server in Settings with “Change key”, which replaces
it in place and keeps the server, its books and places.

Book libraries are scanned (podcast libraries are left out; Lelap follows podcasts by RSS). Each
item becomes one book from its tracks in Audiobookshelf's order; in a book of several files each
file is a chapter named after the Audiobookshelf chapter it starts in. Tracks stream as the
original file with the key as a `Bearer` header on Android and `?token=` in a browser. Places go
both ways: a scan reads `mediaProgress` and the newest change wins, the place is read again
before a book plays, and the app sends `PATCH /api/me/progress/{id}` at start, pause, about every
five minutes and the end of a book. No migration: the server is a new kind in
`library_roots.remote`.

Done when a book started in Audiobookshelf's own web player continues in Lelap at the same place,
and back.

## Open checks

- [ ] (you) **API key and libraries.** On Audiobookshelf 2.26 or later, make a key in Settings → API
      Keys, add the server with it, test the connection, check the book libraries are picked and
      podcast libraries are not listed. A server behind a path (`https://host/audiobookshelf`) too.
- [ ] (you) **Refused key.** Turn the key off in Audiobookshelf, then play a book or rescan: Settings
      shows “Audiobookshelf refused the API key” with “Change key”. Enter a new key: the books and
      places stay, and the mark goes.
- [ ] (you) **Books.** A library with single `.m4b` books (chapters shown), books of several `.mp3`
      files (one book, parts in order, a chapter per file) and a book with excluded files. Check
      titles, authors and covers.
- [ ] (you) **Playback.** Plays the original file, seeks, and downloads with the header, also a download
      that waits for Wi-Fi.
- [ ] (you) **Web.** On the web build, a server that allows the site lists books, plays with `?token=`
      and reports places; one that does not shows the CORS hint.
- [ ] (you) **Two-way progress.** Play in Lelap, pause, and check Audiobookshelf's web player resumes
      there; play further in the web player, then play in Lelap, and check it starts at that place.
      Finish a book in Lelap and check it shows finished in Audiobookshelf, and the other way.
- [ ] (you) **Casting.** A cast device can't send headers: casting an Audiobookshelf book may need
      `?token=` in the address instead. Check with Chromecast and a UPnP renderer.
