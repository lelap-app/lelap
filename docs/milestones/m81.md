# M81 Test round 2

Most work since M40 has never run on a phone. This milestone runs every `(adb)` open check
(`pnpm checks --adb`) on the maintainer's Pixel with the current beta, records the round in
`docs/testing.md`, ticks what passes, and fixes what fails, one pull request per area.

- Run the checks area by area: playback, library and covers, downloads, sync, casting, car and
  widget, podcasts, add-ons, web.
- Fix failures here when they are small; open a planned milestone for anything larger.
- The Find chapters fix from M64 (start at once, progress bar) was built in [M85](m85.md); its
  checks are there.

Done when no `(adb)` check older than this milestone is open without a reason, and a beta with the fixes is out.

  and the reboot last, together with session 6's waits if they run the same day.

  "looks like music" card and M109/M115's series tags all read the same scan. M16's tags, lists
  and backup reuse the same books.

  stopped at …" history line on the way.
- **5:** one LibriVox book downloads for M4, M63 and M151. Wi-Fi off and "Download only while
  charging" go together. M53's folder moves need the USB stick; M64's "kill the app while downloads
  move" runs in the same move.
