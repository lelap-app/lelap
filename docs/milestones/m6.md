# M6 Web build

The react-native-web build of `apps/app` with sql.js on OPFS, the web audio adapter and web
downloads, deployed to `listen.lelap.app` (Pages project `lelap-web`), and the feed and cover
proxy in `services/proxy` on `proxy.lelap.app` with a rate limiting rule. Live since 2026-11-16.
Web downloads need CORS on the audio host and stop when the tab closes. Design notes:
[the brief](../brief.md#web).

Done when the same library plays in a desktop browser at `listen.lelap.app`.

## Setup

The Pages project `lelap-web` serves the web app on its own host. The `web` environment sets
`PROXY_DOMAIN` and `WEB_ORIGIN` (the web app's origin); without them the proxy deploys to
`workers.dev` and allows any origin. The free plan's rate limiting rule covers the proxy hostname.
