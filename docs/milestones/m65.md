# M65 Server sources 2

What the built-in and bundled server sources (Jellyfin, Audiobookshelf, Subsonic, Plex, Emby, SMB and SFTP) left out.

- Jellyfin reports have no outbox, so a place reported while offline is lost. (M36)
- Jellyfin reports go out only while the app runs. (M36)
- Audiobookshelf reports have no outbox and go out only while the app runs. (M41)
- Audiobookshelf narrators and series are read but the library has no field for them (Jellyfin narrators are in [M40](m40.md)). (M41)
- Chapters inside the files of a multi-file Audiobookshelf book; today each file is one chapter. (M41)
- A track with an unknown extension is dropped without a word, and a book without a title is named after its item ID. (M41)
- When the profile that added the server is deleted, places come in for the first profile but none go back out. (M41)
- The player resolves a file’s redirects once per book load; a later, different redirect gets the login only if it stays on the server’s own host. (M57)
- A place at 0 is reported when playback starts, before the player moves to the saved place, and a scan in between takes it. Jellyfin and Audiobookshelf do the same. (M58)
- With only a music folder chosen, albums are read with one `getAlbum` each; thousands of albums may need the 2-minute listing limit raised. (M58)
- Older bookmarks of a book are tidied only after the next scan once the app restarts. (M58)
- Bookmark times compare the server’s clock with the phone’s, so a server clock running ahead lets an older bookmark win. (M58)
- When a Plex server’s address changes, the listener must sign in again; the add-on reaches only the addresses in the form. (M59)
- File addresses are those of the address that answered at the last scan; after leaving home, books play only once a scan has found the server away. (M59)
- A Plex place saved after an app restart lists the libraries again first, which may run past the 20 s a place report may take on a large library. (M59)
- The identity check runs before listing, not before each stream, so an address that later answers as another server still gets the stream header. (M59)
- Emby paging is sorted by name only, so items with the same name could move between pages (repeats are dropped, gaps are not). (M59)
- A download’s `job.json` keeps login headers (and an SFTP private key) until the download is removed; drop them once every file is done. (M62)
- The connection pool’s handshake gates per server are never removed (one small object per server and login). (M62)
- On Android 17, library servers at a local network address (SMB, SFTP, WebDAV, Audiobookshelf, Jellyfin and others) don’t ask for the local network permission, so scans and playback from them can fail. Casting asks through `LocalNetwork` in `modules/cast` (#145); ask the same way, with an explanation, before scanning or playing from a LAN address. (M26)

Done when places reported offline reach Jellyfin and Audiobookshelf later, and narrators and series show for server books.
