# M23 Podcasting 2.0

`parseFeed` (`packages/core/src/podcasts`) reads the feed's `podcast:` namespace (chapters files,
transcripts, people, seasons, episode numbers, funding, `podcast:guid`) and keeps it as JSON in an
`extras` column on podcasts and episodes (migration `0009_podcasting`). An episode without
embedded chapters gets its chapters file when it starts playing; the player opens a transcript
that follows the position, and a tap on a line seeks; the podcast page shows hosts, guests,
seasons and a “Support this show” link. The web app reads chapters files and transcripts through
the proxy's text-only `/text` route (UTF-8 text, 5 MB at most, never audio).
