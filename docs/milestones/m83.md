# M83 Accessibility 2

Accessibility has been checked screen by screen as features landed. This is one pass over the
whole app in one go.

- TalkBack: every control named, order sensible, actions on rows, live regions where things
  change.
- Large text (font scale 2.0) and display size: nothing cut off, nothing overlapping.
- Contrast in both themes; touch targets of at least 48 dp.
- The web app with a screen reader and keyboard only.

Done when the whole app is usable with TalkBack alone and at the largest font scale.
