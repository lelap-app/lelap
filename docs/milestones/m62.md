# M62 SMB and SFTP

SMB shares (Windows, Synology, QNAP, Samba) and SFTP folders are built-in library sources on
Android, through the Kotlin module `modules/netfs`: books scan into the library like WebDAV's
(a bounded walk that skips NAS folders such as `@eaDir`), play with a read-ahead buffer, download,
and cast through the phone, with the login sealed on the phone. SFTP shows the server's host key
before the first login and refuses a changed one. Both need raw sockets, so the web app says they
are in the Android app only; see Own storage in the [brief](../brief.md#decisions). Checked
against Samba and OpenSSH in Docker from the JVM; nothing has run inside the app on a phone yet.

Done when a Synology share and an SFTP folder scan, play and download on Android, with the app
closed too.

## Open checks

- [ ] (you) Synology: Settings → Add a server → SMB, `smb://<nas>/<share>/Audiobooks` with a DSM user:
      books appear with titles, covers (embedded and `cover.jpg`) and chapters.
- [ ] (you) An SMB book plays, seeks far ahead at once, keeps its place, and plays on with the screen off
      and the app swiped away.
- [ ] (you) An SMB book downloads, also one that waits for Wi-Fi, and plays in airplane mode.
- [ ] (you) SFTP with a password: “Test connection” shows the host key; it matches
      `ssh-keygen -l -f /etc/ssh/ssh_host_ed25519_key.pub` on the server; Connect adds the books.
- [ ] (you) SFTP with a private key, pasted and picked as a file, with and without a passphrase.
- [ ] (you) Change the SFTP server's host key (or point the address at another server): the next scan
      leaves the books as they are and Settings says the key changed; a book from it does not play,
      and a download stops with the same message.
- [ ] (you) Change the SMB share's password: Settings shows “The server refused the login” with Log in;
      logging in again keeps books and places.
- [ ] (you) Cast an SMB book and an SFTP book to a UPnP speaker and a Chromecast: the phone serves the
      files, seeking works.
- [ ] (you) A Windows 11 share with a Microsoft account and with a local account, and `DOMAIN\name` on a
      domain.
- [ ] (you) QNAP and Samba on a Raspberry Pi.
- [ ] (you) The web app: Add a server → SMB or SFTP says it is in the Android app only.
