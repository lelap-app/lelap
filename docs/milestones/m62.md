# M62 SMB and SFTP

**Status:** in progress. SMB shares and SFTP folders scan, play, download and cast on Android
through a new `modules/netfs`; phone checks are in [m62-follow-ups.md](../m62-follow-ups.md).

Built-in sources for home NAS boxes and plain servers: SMB (Windows shares, Synology, QNAP, Samba
on a Raspberry Pi) and SFTP. Both need native sockets, so they live in a Kotlin module and work
on Android only; the web app can't reach them. Books scan into the library like WebDAV's and play
and download with the login kept sealed on the phone.

## Done when

- A Synology share and an SFTP folder scan, play and download on Android, with the app closed too.
