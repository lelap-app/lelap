# M3 Add-on protocol and SDK

The protocol and SDK docs (on the site under `/docs`), the TypeScript SDK in `packages/sdk`, the
Workers template in `services/template`, the Catalog and LibriVox add-ons in `services/catalog`,
and the Home, Discover and Search screens. Finding a LibriVox book in the app and playing it
passed on a phone. Design:
[`superpowers/specs/2026-11-16-m3-addon-protocol-design.md`](../superpowers/specs/2026-11-16-m3-addon-protocol-design.md);
the protocol's essentials are in [the brief](../brief.md#add-on-protocol).

## Open questions

- The published JSON Schema rejects unknown fields while the app drops them; decide which one the
  protocol promises before third parties build on it.
- Streams for `episode` items were specified loosely, to be settled in M5; check that the episode
  ID convention is written down in the protocol docs.
