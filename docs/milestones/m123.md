# M123 Server sources 4

What [M100](m100.md) left out.

- Places for add-on servers (Subsonic, Plex, Emby) wait until the app opens: the background
  refresh has no sandbox to run an add-on in, since the WebView lives in the app's screen. Needs a
  sandbox that starts without the UI, or the add-on's place call made natively.
- Places saved with the app closed go out with the background refresh, about hourly, not at once.
  The playback service could queue a WorkManager job of its own on pause.
- `locate` runs only when the app loads a book. Up Next, Android Auto and the widget start books
  with the app closed from the last scan's addresses, and downloads use them too.
