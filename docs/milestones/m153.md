# M153 Stream choice

Today each source add-on sorts and filters its own streams, so a listener's wishes (“prefer
M4B”, “English first”) live in every add-on's settings and never apply across them, and two
add-ons that find the same files list them twice. With [M152](m152.md)'s `format`, `language`
and `releaseId` the app can do it once. Kept small on purpose: three settings, no rules editor.

- **Settings → Streams:** preferred formats in order, preferred languages (default: the
  profile's languages), and “Show streams that are still preparing” (on). Per profile, synced.
- **Order on the item page:** streams in a preferred language first, then by preferred format,
  then in the add-ons' own order. Nothing is hidden except preparing streams when that switch is
  off; a stream with no `format` or `language` sorts after those that match.
- **Duplicates:** streams with the same `releaseId` show as one row naming every add-on that has
  it; playing it uses the first add-on that is ready, then the next on failure.
- Words to hide, minimum bitrate and similar filters wait until listeners ask for them.

**Done when** two test add-ons that offer the same release as MP3 and M4B show it as one row,
M4B first for a listener who prefers it, and the order follows the profile to another device.
