# M122 Better sound 3

What [M101](m101.md) left out.

- Skip silence on the web knows constant-bitrate MP3s only. Variable-bitrate MP3s could use the
  Xing table of contents, and M4B, Opus and FLAC need their frames found through the container
  (or WebCodecs' `AudioDecoder`).
- On a stream, skip silence reads the file a second time with range requests, beside the
  element's own. Playing the element from the same bytes (Media Source Extensions) would read it
  once.
- Receivers that could apply the effects themselves get none; no protocol Lelap casts with
  offers them today.
