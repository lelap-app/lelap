# M107 Car and Bluetooth 3

The leftovers from [M74](m74.md), until now under Future goals in the roadmap.

- **Car mode sideways on phones.** Lift the app's portrait lock for the car mode screen only
  (`expo-screen-orientation`), with a layout for a phone in a landscape car holder: big controls
  on one side, the cover and chapter on the other.
- **Covers per car app.** Grant each connected car app read access to the covers it asks for,
  instead of exporting the cover provider.
- **Headphone drain once per session.** Write the battery drain of a headphone session once, so an
  app restart mid-session doesn't count that session twice.
