# M126 Speed and battery 2

What [M106](m106.md) measured but didn't change.

- **Android's start.** The first screen waits for the migrations and up to 1.5 s for the playback
  service's journal (`JOURNAL_WAIT_MS` in `apps/app/src/player.tsx`). Time both with M106's cold
  start check and draw the first screen sooner where the numbers say so.
- **The Library rereads every book on each change.** Any `refresh()` (a pause, a finished
  download) reads all 10,000 books again, about 70 ms on the web. Read only the books that changed.
- **A smaller start bundle on the web.** zod's JSON Schema code (about 38 KB), the RSS parser
  (about 90 KB with its entities) and the bundled add-ons (83 KB) load at start though the first
  screen needs none of them.
- **Saving on the web off the main thread.** A save fingerprints 49 MB in about 27 ms on a Mac,
  more on a phone's browser; a worker could do it, or SQLite's own page list could say which
  chunks changed.
