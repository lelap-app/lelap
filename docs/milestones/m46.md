# M46 Recommendations

Up to two “Because you finished …” rows on Home, worked out on the device for each profile from
the books it finished, its listening time per author and the catalog pages Home already loads. A
row can be hidden from Home and shown again in Settings → Catalogs. The scoring is in
`packages/core/src/recommend.ts`; `recommend.test.ts` also checks that suggestions make no request
beyond Home's own first-page requests. The privacy rule is in the
[brief's Decisions](../brief.md#decisions).

## Requests

The feature adds none. Every request it leads to is one Home makes anyway:

| Request                                         | Why it reveals nothing new                                                                                                                                                                                                                                                       |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /catalog/audiobook/{id}.json` per Home row | The same URL and query key as Home's own row, without extras, so it is served from the same cache; `recommendationCatalogs` takes no profile or library.                                                                                                                         |
| Cover images (`cover` of a catalog item)        | Only for items among the first ten of a page, which Home's rows draw unscrolled (`HOME_FIRST_DRAWN`), and, since M118, for a cover address Home's rows showed on screen this session (`SessionCovers`, in memory only). Other items show the title's letter. No artwork request. |
| None for sources                                | Suggestion tiles don't ask add-ons for streams; a badge shows only what an earlier lookup found.                                                                                                                                                                                 |

A cover from the session's set was fetched for Home already, so the image cache usually answers. When
the cache dropped it, the same address is fetched again: its host learns only that it was wanted a
second time, not why. The maintainer accepted that in M118. The set lives in
`apps/app/src/sessionCovers.ts`, is never saved or synced, and is gone when the app closes.

Opening a suggested item makes the item page's usual meta and stream requests, as for any item the
listener opens. The scoring reads only the database and pages already loaded; it has no fetcher.
`recommend.test.ts` (“what suggestions ask add-ons for”) checks that the requests are the same for
an empty library and a busy one, are among Home's first-page requests, and carry no finished title,
author or ID. “Covers on suggestion tiles” checks that a tile shows only covers Home's rows showed, whatever
the profile finished.

Done when Home shows a row of suggestions that changes with what the profile finishes, with no
request that carries listening history.
