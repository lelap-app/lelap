# M98 Developer verification

Android requires verified developers for apps installed outside the Play Store, in stages from 2026. Last in this batch by the maintainer's choice, but it can block distribution, so watch the
dates.

- Find what the requirement means for Lelap's APKs, F-Droid builds and Obtainium.
- Register the developer identity if needed, and record the decision in the brief.

Done when Lelap's APKs install on a phone that enforces verification.
