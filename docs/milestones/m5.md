# M5 Podcasts

RSS subscriptions, OPML import and export, auto-download rules per podcast and the Up Next queue,
in `packages/core` and the Podcasts tab. Unsubscribing keeps the episodes and their places, so
subscribing again picks them up. Design:
[`superpowers/specs/2026-11-16-m5-podcasts-design.md`](../superpowers/specs/2026-11-16-m5-podcasts-design.md).

Done when the maintainer's own podcast subscriptions have moved over.

## Open checks

- [ ] (adb) Long-press each podcast folder → This is a podcast…: played episodes and the current place
      carry over.
- [ ] (adb) A podcast from Search opens with episodes from its feed; Subscribe adds it to Podcasts
      (needs the Podcast Index keys on the catalog Worker).
- [ ] (adb) OPML: export, push the file back, import it; nothing is duplicated.
- [ ] (adb) Auto-download with 3 newest: three download; marking one played removes it and fetches the
      next.
- [ ] (adb) Pull to refresh fetches new episodes; an unchanged feed answers 304 (check in logcat or the
      proxy).

- [ ] (you) Podcast search needs `PODCASTINDEX_KEY` and `PODCASTINDEX_SECRET` on the catalog Worker
      (`wrangler secret put`); try trending and a search.
