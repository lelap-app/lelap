# M110 Upkeep

Small leftovers from Future goals, taken between bigger milestones.

- **First start ([M82](m82.md)):** “Free books to play now” names the default add-ons this build
  installed (“LibriVox and Open Library catalog are already installed. Their free books are on Home.”), not
  LibriVox by name; a build without default add-ons leaves the choice out (`apps/app/app/welcome.tsx`,
  `formatNames` in `apps/app/src/format.ts`). `needsFirstStart` (`packages/core/src/firstStart.ts`)
  also treats an add-on the listener installed, a default add-on they removed, a sync group
  (`hasSyncMembership`) and the profile's listening history as an install in use.
- **Scan and play on the emulator ([M94](m94.md)):** after the empty Library,
  `scripts/emulator-smoke.sh` pushes a one-minute WAV to `Download/LelapSmoke/SmokeBook`, taps
  “Choose your audiobooks folder”, drives the system folder picker by its text (Download,
  LelapSmoke, “Use this folder”, “Allow”), waits for the scanned book, taps it and waits for
  `LelapPlayback: Playing` in logcat, which `PlaybackService` now writes when playback starts or
  stops. The release build gets no test-only way in. On a failure the script prints the last
  screen's text and the end of logcat into the CI log. The job's triggers are unchanged.
  `EMULATOR_ABI=arm64-v8a scripts/emulator-apk.sh` builds for an emulator on an Apple silicon Mac.
- **Developer setup ([M2](m2.md)):** `apps/app/metro.config.js` keys Metro's cache on the
  migrations' contents, so an edit to an existing `.sql` reaches the app after a Metro restart
  instead of hiding behind Babel's inlined copy. `.claude/launch.json` runs each server through
  `scripts/dev-node.sh`, which takes Node 24 from `PATH`, nvm or fnm, and says so when none is
  there. Both are in `apps/app/README.md`.
