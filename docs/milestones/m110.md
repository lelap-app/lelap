# M110 Upkeep

Small leftovers from Future goals, good to take between bigger milestones.

- **First start ([M82](m82.md)):** the "Free books" choice names LibriVox even in a build whose
  default add-ons leave it out; name the installed ones instead. An install with only add-ons,
  sync or listening history and no books sees the welcome once after updating; count those in
  `needsFirstStart` too.
- **Scan and play on the emulator ([M94](m94.md)):** the emulator smoke test stops at the empty
  Library. Scan a pushed folder and play a file, with the folder picker driven or a debug-only way
  to add a folder, and check in logcat that playback started. Keep the job off ordinary pull
  requests, as today.
- **Developer setup ([M2](m2.md)):** Babel's cache hides edits to existing `.sql` migrations (say
  so in the docs or clear it in the script), and `.claude/launch.json` assumes `~/.nvm/nvm.sh`.

Remove these items from Future goals in the roadmap when this milestone is done.
