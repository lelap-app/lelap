# M100 Server sources 3

What [M65](m65.md) left out because it needs native work or a protocol change.

- Places go out only while the app runs: the outbox keeps them until the app starts or comes to
  the front. A place saved by the playback service while JavaScript doesn't run is not queued at
  all; the next scan settles it. Needs a WorkManager job, or the service queuing places itself.
  (M36, M41)
- The player resolves a file's redirects once per book load; a later, different redirect gets the
  login only if it stays on the server's own host. A data source that follows redirects per request
  would fix it; the player and casting both have their own `LoginRedirects`. (M57)
- When a Plex server's address changes, the listener must sign in again: the add-on reaches only
  the addresses in the form. Needs a way for a library listing to hand back new settings. (M59)
- File addresses are those of the address that answered at the last scan; after leaving home,
  books play only once a scan has found the server away. Needs alternative addresses per file, or
  a hook before each stream. (M59)
- The identity check runs before listing, not before each stream, so an address that later
  answers as another server still gets the stream header. The same hook would cover it. (M59)
