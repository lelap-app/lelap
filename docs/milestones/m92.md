# M92 Hardcover sign-in

Hardcover's docs recommend OAuth over pasting a personal access token. The add-on protocol
already has sign-in (revision 7).

- Register Lelap as a Hardcover OAuth app; sign in through the browser and come back.
- Short-lived tokens, renewed by the add-on; the listener can revoke access on Hardcover.
- Pasting a token stays possible for self-hosters.

Done when a listener adds Hardcover without ever seeing a token.
