# M92 Hardcover sign-in

The Hardcover add-on's configure page offers “Sign in with Hardcover” first. Hardcover asks the
listener to allow Lelap in and sends them back; the rows page of the new add-on address follows,
and the address goes back to the app as before. The listener never sees a token. Pasting a
personal token stays, folded under “Or paste a token you make yourself”, and is the only way on a
server without sign-in. How the tokens are kept is in the brief (Decisions, “Hardcover sign-in”).

- **OAuth:** authorization code with PKCE (S256) as a confidential client, `state` in a sealed
  `HttpOnly` cookie for this browser, `iss` checked (RFC 9207), scopes `read:me:content`,
  `read:library`, `write:library`, `read:catalog` and `read:lists`
  (`services/catalog/src/scrobble/hardcover-oauth.ts`, `hardcover-signin.ts`). Endpoints and
  token rules from [Hardcover's OAuth docs](https://docs.hardcover.app/api/oauth/): access tokens
  last a week, refresh tokens six months and change on every use.
- **Grants:** the add-on address holds a sealed grant ID and key; the server keeps the tokens
  sealed with that key and renews them a day before they run out, one renewal at a time
  (`hardcover-grants.ts`). On Workers each grant is a Durable Object (`hardcover-grants-do.ts`,
  `wrangler.toml`), dropped after 190 days unused; on Docker a file in the secrets volume
  (`docker/server/src/grantFiles.ts`). Revoking Lelap on Hardcover makes the add-on answer 401
  “Sign in to Hardcover again”.
- **Settings:** `HARDCOVER_CLIENT_ID` (a var in `wrangler.toml`, the Docker env) and
  `HARDCOVER_CLIENT_SECRET` (a Wrangler secret, the Docker env). The redirect URL is
  `<catalog origin>/hardcover/oauth/callback`: the request's origin on Workers, `CATALOG_ORIGIN`
  (default `https://catalog.<LELAP_DOMAIN>`) on Docker, whose requests arrive as http behind Caddy.
- **SDK:** `ConfigureText.signIn` puts a sign-in button first and folds the form (changeset
  `m92-configure-sign-in`). No protocol change.
- Links made before (`v1.`, `e1.`, `e2.` with a token) keep working.

Tests against a mocked Hardcover: `services/catalog/test/hardcover-signin.test.ts`,
`docker/server/src/grantFiles.test.ts`, `packages/sdk/src/config.test.ts`.
