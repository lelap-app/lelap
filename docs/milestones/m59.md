# M59 Plex and Emby

**Status:** in progress. Built: Emby and Plex bundled with the app as in-app add-ons. Emby signs
in with a password or an API key; Plex with a code entered at plex.tv/link, then finds the server
at home or away, never through a relay. Audiobook libraries scan as books, the token goes as a
header (in the address only in the browser), and places are kept with the server both ways.
Protocol revision 7 adds `signin` and a library's `webQuery`. Phone and Plex account checks in
[`m59-follow-ups.md`](../m59-follow-ups.md).

Bundled in-app add-ons (M57) for two more media servers next to Jellyfin. Emby's API is close to
Jellyfin's. Plex signs in through plex.tv with a PIN link, then talks to the server on the local
network or its own address; progress syncs both ways where the server keeps it.

## Done when

- An audiobook library on Plex and one on Emby scan into Lelap and continue at the server's place.
