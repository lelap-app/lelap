# M59 Plex and Emby

Emby and Plex come with the app as in-app add-ons ([M57](m57.md)), next to the built-in Jellyfin
(`packages/core/src/addons/bundled/emby.js` and `plex.js`). Emby signs in with a password or an API
key with a username. Plex signs in with a code entered at plex.tv/link, then finds the server at
home or away, never through a relay; the account's token goes only to plex.tv and the server's
only to its checked address. Audiobook libraries scan as books, the token goes as a header (in the
address only in the browser), and places are kept with the server both ways. Protocol revision 7
adds `signin` and a library's `webQuery`.

Done when an audiobook library on Plex and one on Emby scan into Lelap and continue at the
server's place.

## Open checks

- [ ] (you) Add an Emby server (Settings → Servers → Add a server → Emby) with a username and password:
      its audiobook library scans in with covers and chapters, and books play with the screen off.
- [ ] (you) Download a book from Emby on Wi-Fi: it comes from `/Items/…/Download`, and plays in flight
      mode.
- [ ] (you) Play a book from Emby a while and pause, then open Emby's web app: the part shows the place
      (“Resume”). Move the place there, rescan in Lelap: the place follows.
- [ ] (you) An Emby API key with a username, instead of the password: the same books.
- [ ] (you) Plex (needs the maintainer's account): press Sign in, open the link on another device and
      enter the code at plex.tv/link. The form fills in the server and its addresses; plex.tv's
      Authorized Devices lists “Lelap”, once, also after signing in again.
- [ ] (you) With “Audiobooks” as a music library on Plex: the books scan in with covers, play with the
      screen off, and a single-file `.m4b` shows its chapters.
- [ ] (you) Plex away from home (mobile data): a rescan finds the server at its address away from home;
      with remote access off, the scan says it can't reach the server, and nothing plays through a
      relay.
- [ ] (you) Pause a book from Plex, open Plex Web: the track shows the place. Finish the book: the last
      track is marked played.
- [ ] (you) Cast a book from Emby and from Plex: it plays, fetched through the phone, never with the
      token.
- [ ] (you) Restore a backup on another phone: Emby asks for its password again, Plex for a new sign-in.
- [ ] (you) Plex in the web app with a real account: the sign-in, a scan and playback with
      `X-Plex-Token` in the address over a `plex.direct` connection (Plex Media Server's CORS
      headers).
