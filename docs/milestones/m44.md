# M44 Tablet and desktop

On tablets and laptops the tabs become a rail on the start edge and the player stands beside the
open screen; Discover fills the width with more columns. A phone turned sideways shows the Player
with the cover beside the controls. The web app has keyboard shortcuts (Space or K, ← and →, < and

> , / and ?, listed under ?) and fuller media keys through Media Session. When a window gets two
> panes, the pane widths and the keys are decided in `packages/core/src/screen.ts`, tested in
> `screen.test.ts`.

## Open checks

- [ ] (adb) On a 10-inch tablet (or a tablet emulator), upright and sideways: the tabs are a rail, the
      player stands beside the list once a book plays, and tapping a book in the Library plays it
      there without opening the full-screen player.
- [ ] (adb) On the tablet, car mode and the full-screen player (from a notification) hide the pane, and
      Back returns to the two panes.
- [ ] (adb) A phone turned sideways (`adb shell settings put system user_rotation 1` with auto-rotate
      off): the Player shows the cover beside the controls, nothing is cut off under the camera
      cut-out, and turning it back gives the upright Player.
- [ ] (adb) A large phone sideways at the smallest display size (it can reach about 1066 × 480 dp):
      it stays on one pane; if it gets two, raise `WIDE_MIN_HEIGHT` in `packages/core/src/screen.ts`.

- [ ] (you) TalkBack on the tablet reads the rail's tabs and the pane's controls in order: list first,
      then the player.
- [ ] (you) The rail uses React Navigation's `tabBarPosition: 'left'`; with a right-to-left layout
      (forced RTL in a test build, or the first right-to-left language) it moves to the start edge.
- [ ] (you) Media keys on a laptop keyboard in Chrome, Firefox and Safari: Play/Pause plays and pauses
      with the tab in the background; ⏮ and ⏭ skip 30 s; the browser's media overlay shows the
      progress in the current file and can drag within it.
- [ ] (you) Keyboard only in the web app: Tab moves through the rail, the list and the player pane;
      Space on a focused button presses it once and doesn't also play or pause.
