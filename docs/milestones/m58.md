# M58 Navidrome and Subsonic

Subsonic comes with the app as an in-app add-on ([M57](m57.md)) for Navidrome, Airsonic-Advanced,
Gonic and other servers that speak the Subsonic API
(`packages/core/src/addons/bundled/subsonic.js`). It signs in with a salted token (never the
password, never stored in an address), finds audiobooks by genre or by music folder, streams and
downloads them with covers, and keeps places with the server's bookmarks both ways. The app reads
each book's first file for chapters and ISBN or ASIN tags, since Subsonic servers expose neither.
Protocol revision 6 adds a library's sealed `query`, `downloadUrl`, `place` and the `place`
resource.

Done when a Navidrome server's audiobooks show in the library, play and download, and a place
saved in Lelap shows on the server's bookmark.

## Open checks

- [ ] (you) Add a Navidrome server (Settings → Servers → Add a server → Subsonic): its audiobooks scan
      in with covers, play with the screen off, and a single-file `.m4b` shows its chapters.
- [ ] (you) Download a book from it on Wi-Fi: it comes from `download`, not `stream` (Navidrome's log
      says “Downloading”), and plays in flight mode.
- [ ] (you) Play a while, pause, open Navidrome's web player: the song shows a bookmark at that place.
      Move the bookmark in another Subsonic app, rescan in Lelap: the place follows.
- [ ] (you) With the app swiped away, a book from it plays from the notification and from Android Auto.
- [ ] (you) Cast a book from it to a speaker: it plays, and the speaker fetches it from the phone (the
      phone's address in the speaker's app), never with the token.
- [ ] (you) Restore a backup on another phone: the Subsonic server asks only for its password again.
- [ ] (you) Gonic and Airsonic-Advanced: books by genre and by music folder, places kept.
- [ ] (you) A Subsonic server that redirects `/rest/` to another host (an SSO proxy in front of it): on
      Android the request with the token does not reach that other host (`fetch` may follow redirects
      by itself), and the app refuses the answer.
