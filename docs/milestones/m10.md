# M10 Your own storage

WebDAV folders and S3-compatible buckets are library roots next to the phone's folder, built into
the app (`library_roots.remote`, code in `packages/core/src/remote/`). WebDAV lists with
`PROPFIND`, S3 with `ListObjectsV2` (Signature V4), and the folder rules turn files into books.
Android reads tags, covers and chapters over HTTP with the login; the web build reads only
durations. WebDAV files carry the login as a header sent only to that host, so they don't play in
a browser; S3 objects play through pre-signed links. Server settings stay on the device and never
sync. See the own storage decision in [the brief](../brief.md#decisions).

Done when a Nextcloud folder of audiobooks plays on the phone, downloads, and keeps its place.
