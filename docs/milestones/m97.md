# M97 Landing page 3

- **Drawn phone screens, faithful to the app.** The player with Early Mornings at the Laksa Café,
  and Home with Continue listening and the Self-improvement, Growing up and Horror and uncanny
  rows, in English and Malay. Markup and CSS in `PhoneMockup.astro` and `CatalogMockup.astro`,
  sized in the app's own dp on a Pixel 10 Pro XL screen (448 × 997 dp) by `PhoneScreen.astro`, so
  they stay sharp at any size; the app's icons in `AppIcon.astro`, its colours as `--app-*`
  tokens. The app has one dark theme, so the phone keeps the night theme on both site themes.
  The first version of this milestone showed screenshots instead; they looked soft and cut off
  the player's bookmarks button, so the drawings came back in PR 184.
- **The `site-screenshots` skill** (`.claude/skills/site-screenshots/`) makes reference shots of
  the real app to compare the drawings with: it exports the web app against a local demo add-on (a
  made-up book with silent WAV audio made on the fly, the shelves' real titles as metadata only,
  drawn covers rendered by Chrome), drives a headless Chrome with a fresh profile through the
  app's own buttons, and writes PNG files to its work folder, never to the site. No Playwright:
  the Chrome DevTools Protocol over Node's own WebSocket. Expo web only; Android-only screens are
  not shot.
- **Changelog page** (`/changelog`), built from the root `CHANGELOG.md` at build time by
  `src/lib/changelog.ts`, with pull request numbers linked; static, no script.
- **Help page** (`/help`): getting started, add-ons (why there is no add-on directory), your
  library, listening, and what to do when something doesn’t work. English only, like the docs.
  The home page FAQ answer on third-party add-ons uses the same wording and links to it; the
  footer links both pages.

Found on the way, not fixed here (app code): on the web, the player asks the proxy for a
plain-http cover with an already proxied address.
