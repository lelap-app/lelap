# M96 Security review 2

The [second round](../security-audit.md#round-2-m96) of `docs/security-audit.md` (findings 23 to
49): in-app add-ons and their sandbox, sealed settings and configure pages, Hardcover, casting,
the local network permission, SMB and SFTP, the web app's storage, share links, the self-hosting
admin page and the car's cover provider. What needs real devices or a format change is in
[M104](m104.md); enforcing Cast device authentication stays in [M78](m78.md).

- **Add-ons.** The sandbox page holds the worker's messages until it has started, so add-on code
  can't claim to run in the worker and then get settings in the page; the page CSP adds
  `form-action 'none'` ([`page.ts`](../../apps/app/src/sandbox/page.ts)). A link only moves an
  installed add-on to a new address on the same origin
  ([`addonInstall.ts`](../../apps/app/src/addonInstall.ts)). Sandbox fetches drop `Host` and
  other connection headers and refuse a too-large `Content-Length` before reading
  ([`sandboxFetch.ts`](../../packages/core/src/addons/sandboxFetch.ts)); a web add-on claiming a
  sandbox gets the service lines on its review sheet.
- **Covers and sync.** Covers from another device must be `http(s)`
  ([`ops.ts`](../../packages/core/src/sync/ops.ts)); the car's cover provider opens only files that resolve to an image name, and other
  apps' documents ([`CarCovers.kt`](../../modules/audio/android/src/main/java/app/lelap/audio/CarCovers.kt)).
  Share links check a matched work's ID like an add-on's.
- **Casting.** Header count and size limits for the media server and the UPnP reader, and a 15 s
  deadline for the media server
  ([`MiniHttp.kt`](../../modules/cast/android/src/main/java/app/lelap/cast/MiniHttp.kt)); UPnP
  descriptions with a DTD are refused before parsing.
- **Self-hosting.** Admin pages answer only addresses, `localhost` and `ADMIN_HOSTS`; 10 wrong
  tokens lock an address out for 15 minutes ([`admin.ts`](../../docker/server/src/admin.ts)). A
  secrets volume per service, the catalog keeping `secrets`; `SERVICE_BIND` for the service ports;
  `restore` refuses a backup from a newer schema
  ([`backup.ts`](../../docker/server/src/backup.ts)).
- **SBOM.** Each release attaches `lelap-<version>-sbom.cdx.json` (CycloneDX, from `pnpm sbom`),
  made in a job without secrets; images carry BuildKit's SBOM attestation. CI makes the same SBOM
  on every pull request.

Done when `docs/security-audit.md` has a second round and its findings are fixed or planned.
