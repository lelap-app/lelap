# M96 Security review 2

Since the M19 audit: in-app add-ons and their sandbox, sealed settings, casting and device
authentication, the local network permission, SMB/SFTP, the web app's storage.

- Review each with the same method as `docs/security-audit.md`; fix what is found.
- Enforce Cast device authentication if M78 hasn't.
- A software bill of materials (SBOM) with each release.
- Self-hosting, left from M95's review: a `Host` check on the admin pages against DNS rebinding of
  `/health`; give the internet-facing `proxy` no access to `config_secret` (a secrets volume per
  service); a `SERVICE_BIND` setting so the service ports can stay on loopback behind the bundled
  Caddy; refuse restoring a sync backup from a newer schema than the image knows; per-address
  limits on wrong admin tokens.

Done when `docs/security-audit.md` has a second round and its findings are fixed or planned.
