# M149 UI consistency 2

The second half of the UI review of 2026-11-20, built on M148's shared parts. Where M148 changes
how things are drawn, this one changes what the listener sees and reads, so it needs a few
decisions and Malay lines.

- **Tab header:** the same title height on all five tabs and a Settings gear last on each (today
  only Home and Library reach Settings, through a sliders icon that reads as a filter). Home keeps
  Stats; Podcasts shows Up next as an icon like Library's Bookmarks; the add-on count on Home
  moves to Settings › Library and sources.
- **Desktop rail:** wide enough for its labels (“Discov…” and “Podca…” today), shown on detail
  pages such as Settings and a book too, with Settings at its foot.
- **Settings rows:** a row that opens another screen is a whole-row chevron with its state as the
  detail (Help › Diagnostics, People and devices › Profiles and Sync, Library and sources ›
  Add-ons, Downloads and storage › downloaded books); an amber word only acts (Export, Import,
  Choose, Keep), flush with the edge.
- **Type scale:** named presets (title, section, body, detail, caption) and two heading levels on
  settings pages; Look and language and Listening move to the small-caps section heading, and the
  orphan “Sound for every book and show” paragraph gets its own. Inline `fontSize` values and
  `text-[10px]` move onto the scale.
- **Names:** the Stats page stops being “Listening” (Settings has a page of that name); the row
  inside Downloads and storage stops repeating its page's name; “Sleep” and “Sleep timer” become
  one name; Transcript stops saying “episode” for a book; “show” becomes “podcast”;
  “Long-press” everywhere; the Year page title stops repeating “2026 in sound”.
- **Copy pass** with the `lelap-voice` skill: “Metadata only” on covers (say no audio yet, or drop
  the badge and lean on “Playable only”), “Import OPML” and “Feed address (RSS)”, “Up Next” in
  sentence case, one percent format (“0%”, as the player writes it), “Not on this phone” in the
  browser. Malay lines for all of it.
- **Home and Library:** Library drops the Continue listening card that repeats Home's; desktop
  Home hides it while the player pane shows the same book.
- **Small polish:** the chosen accent keeps its colour dot; the two theme-file links become two
  rows; one moon in the Sleep timer sheet, not six; the first week label in Stats isn't cut
  (“28 S…”); months as three letters (“Sept”); the hard-coded `bg-[#2d3a63]` for lists with a rule
  comes from a token; the player's cover and time buttons get accessible names on the web.

Decisions to make before building, then record with the `record-decision` skill: the new name of
the Stats page, the cover badge for books without audio, and whether the add-on count leaves Home.

Renamed labels break the `site-screenshots` script, which clicks by label (“Sleep”, “Continue
listening”): update `shoot.mjs` and the landing page drawings in the same pull request.

**Done when** every tab has the same header with Settings, the desktop rail shows full labels on
every page, settings rows navigate one way, and no screen uses a size off the scale or a name
another screen uses for something else.
