# M143 UI consistency

A review of every screen at phone and desktop width, in light, dark and one more theme, compared
the current UI with a suggested one, finding by finding, in an Artifact (2026-11-20). This
milestone builds only the findings the maintainer approves from it.

- Fill this file from the review: one line per approved finding, with the screen, the component
  and its size.
- Prefer one shared component or token over fixing each screen; remove a variant rather than add one.
- No new settings. A finding that needs a setting to please both sides is dropped instead.

**Done when** every approved finding is built, the web preview shows each one next to its
mockup, and nothing was added that the review didn't ask for.
