# M148 UI consistency 1

The UI review of 2026-11-20 found the same parts drawn by hand on each screen, so they drift:
screen titles sit at four heights, the amber button is written out 15 times with 8 paddings, and
empty states come in four shapes. This milestone adds the shared parts and swaps them in. It
changes how screens look, not what they do; the one behaviour change is that a page that fails to
load stops spinning. Names, copy and navigation follow in M149.

Build it after the milestones that are editing screens now have merged (M126, M130, M134, M135,
M136, M139, M98), or rebase onto them, since it touches nearly every screen.

- **`ScreenHeader`** (`title`, `subtitle?`, `back?: 'back' | 'close'`, `action?`): back row 48,
  title `text-3xl` at the same height on every pushed screen. `SettingsPage` uses it; so do the
  about 20 screens that copy the back `IconButton` today, Transcript and the chapter editor
  included.
- **`Button`** (`kind: 'primary' | 'secondary' | 'text'`, `size: 'md' | 'sm'`): 48 tall, one
  disabled look per kind (lower opacity, not grey text). `TextButton` becomes its text kind. It
  replaces the hand-built `rounded-full bg-amber` pills, “Set up” on Add-ons and the dashed
  “+ List” on Library; the same verb gets the same kind everywhere (“Add” beside a field is
  secondary on Add-ons, Podcasts and Profiles).
- **`EmptyState`** (`title`, `body`, `action?`, `lori?`): Lori on whole-screen empties (Podcasts,
  Up Next, Downloads, Series, Lists, Transcript, Bookmarks, Search), the same type without her in
  sheets and sections.
- **`LoadState`**: loading, error with Try again, ready, with a timeout. Podcast, Series, Item,
  Add-on, Place and the scrobbler page use it; today a podcast that can't be found spins forever.
- **`Notice`** (`tone: 'info' | 'warning'`) on theme tokens, for the offline banner in
  `app/(tabs)/library.tsx` and the headphone battery warning in `src/devices.tsx`, which both use
  fixed dark colours and look wrong on Day and Sepia. The offline sentence goes through `t()` with
  a Malay line.
- **`TextField`**: one bordered style (`border-line`, 48 tall, 12 inset, amber border on focus)
  for the 13 text inputs, which are bordered or filled today.

The review's screenshots and drawn suggestions are in its artifact (findings 1 to 5 and 10); the
landing page draws Home and the Player, so run the `site-screenshots` skill afterwards.

**Done when** every pushed screen's title sits at the same height, no screen builds its own amber
pill, back row, empty state or text field, and the offline banner reads well in all six themes.
