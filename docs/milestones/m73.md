# M73 Landing page polish

Findings on the site (`apps/site`) left for later, all fixed here.

- Fixed: the theme switch says its new name through an `aria-live` region after a press, and shows
  it in a tooltip on hover and keyboard focus. (M55)
- Fixed: other open tabs follow a theme change through a `storage` listener, without announcing
  it. (M55)
- Fixed: `.visually-hidden` is one shared class in `global.css`; the language switch's long name
  is simply hidden on phones, since the link's `aria-label` already holds it. (M55)
- Fixed: at 320 px the header stays on one row (the GitHub button keeps only its icon below
  375 px) and the hero's and catalog's phone mock-ups shrink to the screen. (M55)
- Fixed: the manifest builder's inputs use a new `--field-line` border with at least 3:1 on every
  page background in both themes, checked in `test/contrast.test.ts`. (M55)
- Fixed: lines that go into `set:html` use `html()`, which escapes what fills their `{holes}`; the
  docs links carry `hreflang="en"` in the line itself instead of a hole. (M48)
- Fixed: on phones in the beta, the hero shows only “Try the Android beta”; “Follow on GitHub”
  and “Read the plan” hide below 560 px, and GitHub stays in the header. (Maintainer)

Done when the site passes its contrast test at 320 px and the switch is announced.
