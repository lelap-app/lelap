# M21 Translations

The app in English and Bahasa Melayu, chosen per profile. `apps/app/src/i18n` has `t()` with the
English text as key and `{holes}` for values; Malay lives in `catalogs/ms.json` (since M48) and
falls back to English line by line. Settings → Language is the profile's `language` setting: a new
profile starts with its creator's language, and switching language or profile redraws the app.
`pnpm --filter @lelap/app test` checks the catalog against the code; `src/i18n/README.md` is for
translators. Native Android text and the landing page followed in [M48](m48.md).
