# M131 Lepak

“Lepak” is Malay slang for hanging out. This add-on gathers free podcasts in Malay and Indonesian,
and from Singapore, as catalog rows from Podcast Index by language. Podcasts only: no book rows.
One of Lelap's own add-ons, off by default:
[Lelap's own add-ons](../brief.md#decisions) in the brief.

## What shipped

- **The add-on** runs on the catalog service: `services/catalog/src/lepak/addon.ts` answers
  `/lepak/manifest.json` as `app.lelap.lepak`, with the Podcast Index key the Catalog already
  uses. Without both Podcast Index secrets it is not served and the root listing leaves it out.
  The add-on and its rows carry Malay names; the manifest's description is English and credits
  Podcast Index, as the Catalog's does.
- **Four rows**, each a catalog of `podcast` items, by category names from Podcast Index's
  list (the [Podcast Namespace `categories.json`](https://github.com/Podcastindex-org/podcast-namespace/blob/e480a7ae042e3357fb3418f604f7f30215fcc810/categories.json)
  that `cat` points at):
  - **Cerita**: Fiction, Drama, Stories;
  - **Sembang**: Society, Culture, Comedy, Leisure;
  - **Sejarah**: History;
  - **Singapura**: no category; feeds that say `en-SG`, `zh-SG`, `ms-SG` or `ta-SG`. Feeds that
    only say `en` or `zh` can't be told apart from any other English or Chinese show, so they are
    left out.
- **Language, asked and then checked.** The first three rows ask with
  `lang=ms,ms-my,ms-sg,ms-bn,id,id-id,in,in-id` (`in` is the old code for Indonesian; RSS uses
  two-letter codes, so `ind` and `msa` are left out), Singapura with
  `lang=en-sg,zh-sg,ms-sg,ta-sg`. Whether Podcast Index matches region forms is not documented,
  so both are sent, and every feed is kept only when its own `language` is Malay or Indonesian in
  any region (or, in Singapura, ends in `-SG`). A row is trending shows first, filled from
  `recent/feeds` when fewer than 20 are trending, then from a search for the row's own word
  (`cerita`, `sembang`, `sejarah`; the same question as Lepak's search, so one cached answer).
  The search came after the first production run: few Malay and Indonesian feeds carry a
  category, so Sejarah was empty while a search for “sejarah” found 30. Recent feeds list no
  author, cover or description, which the GUID lookup (`podcasts/byfeedid`) brings
  (`services/catalog/src/podcastindex.ts`; an empty listing field no longer hides the lookup's,
  which the Catalog's trending row gains too). An empty row is not drawn on Home.
- **Search** (“Lepak”) asks `search/byterm`, which has no language filter, and keeps Malay,
  Indonesian and Singapore feeds by their `language`. It asks exactly what the Catalog's podcast
  search asks (`max=30`), so one cached answer serves both; its shows also appear under the
  Catalog's Podcasts, and an English word mostly finds nothing here.
- **Caching.** Rows and their upstream calls are kept for a day through `upstream.json` (the
  Catalog's trending row: 6 hours; these lists are short and change slowly), search for 6 hours,
  feed lookups for a day: the calls are the same however many listeners add it. A row whose
  recent-feeds top-up or a lookup failed keeps what it has and is cached for 5 minutes.
- **Offered, off by default.** `hostedAddons` in `apps/app/src/config.ts` lists `lepak` with
  `setUp: 'add'`; `OwnAddons.tsx` names it and looks its description up by add-on ID, under
  Settings → Library and sources → Add-ons and in the first-start welcome. An `add` offer shows
  only when the catalog host's root listing names its manifest (or the listing can't be read), so
  a server without Podcast Index keys doesn't offer Lepak. The Malay line is in `ms.json`. The
  welcome reaches the offers from “Free books to play now”, whose title stays: Open lectures there
  are books, and the step itself is called “Optional add-ons”.
- **No books.** Open sources have too little to fill a row: archive.org's copy of the LibriVox
  catalog (`collection:librivoxaudio`) has 1 recording in Indonesian and none in Malay; the 4,868
  openly licensed Malay or Indonesian audio items on archive.org are mostly sermons and radio
  captures; Open Library holds no audio. The maintainer decided against a hand-kept book list.
- **Tests** (`services/catalog/test/lepak.test.ts`, plus the add-on test kit and the worker app):
  the manifest, the language rules, each row's `lang` and `cat`, the recent-feeds top-up, the
  Singapore tags, search filtered by language, and meta. Podcast Index's answers are fixtures in
  its own shapes (`podcastindex-lepak-*.json`); no test reaches the network.

## The language measurement

Not taken yet: the machine that built this had no Podcast Index key. `scripts/lepak-languages.mts`
takes it with the key in the environment. For `podcasts/trending` and `recent/feeds` it prints
each row as the add-on asks it (`lang` and `cat`), with how many feeds come back and how many the
add-on keeps; then each of `ms`, `id`, `ms-my`, `id-id`, `en-sg`, `zh-sg`, `ms-sg` and `ta-sg`
alone, with the `language` values those feeds say. The add-on works either way (see above); the
numbers decide whether Singapura stays.
