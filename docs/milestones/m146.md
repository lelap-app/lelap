# M146 Home and away addresses

Self-hosters often reach their server at a LAN address at home and a public one outside. Today a
server has one address, so they pick the slow one or switch by hand. This is the one new native
feature that serves people who already use Lelap daily.

- A server form gains an optional second address, folded away under “Also reachable at”, so
  servers with one address look as they do now. No setting to choose the order.
- Before a request, use the address that answered last; on a connection error, try the other once
  and remember the winner until the network changes. Downloads and streams in flight keep their
  address.
- The same for SMB and SFTP if it falls out of the same code; not if it needs its own design.
- Tokens are per server, not per address, so signing in once covers both.

**Done when** a phone that leaves home Wi-Fi mid-book keeps streaming the next part from the
outside address without a prompt, and returns to the home address on the next start at home.
