# M35 Add-on trust and art

**Status:** in progress.

- **Before installing.** A sheet replaces the plain “Add X?” dialog: the add-on's description and
  what it can do in plain words, from its manifest and address (`addonPermissions` in
  `packages/core/src/addons/permissions.ts`): the catalogs it shows, details, audio, covers, and
  in amber what deserves a second look: receiving what you listen to (`scrobble`), settings in
  the address, an unencrypted `http` address. It names the host the app talks to. The same sheet
  opens from an add-on's menu (“What it can do”).
- **Artwork.** Protocol revision 3 adds an `artwork` resource
  (`GET /artwork/{type}/{id}.json`). The app asks for it only for items without a cover, picks
  the best square cover (`bestCover`), caches it for a day, and uses it on catalog tiles, search
  rows and the item page. Badges stay the app's own.

Phone checks are in [`m35-follow-ups.md`](../m35-follow-ups.md).

**Done when** installing an add-on shows what it can do before anything is saved, and an add-on
with artwork fills in a missing cover.
