# M35 Add-on trust and art

- **Before installing:** a sheet shows the add-on's description and what it can do in plain
  words, from its manifest and address (`addonPermissions` in
  `packages/core/src/addons/permissions.ts`): the catalogs it shows, details, audio, covers, and
  in amber what deserves a second look (receiving what you listen to, settings in the address, an
  unencrypted `http` address). It names the host the app talks to, and opens again from an
  add-on's menu (“What it can do”).
- **Artwork:** protocol revision 3 adds an `artwork` resource (`GET /artwork/{type}/{id}.json`).
  The app asks for it only for items without a cover, picks the best square cover (`bestCover`),
  caches it for a day and uses it on catalog tiles, search rows and the item page. Badges stay the
  app's own.
