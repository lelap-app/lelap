# M34 Importers

Settings → Backup → “Import from another app” offers three sources. The parsers live in
`packages/core/src/importers/` and apply through the same functions the app uses (tags, finished
marks, subscribe, saved places), stamped with the import time so sync sends them on. Each import
ends with a summary of what matched and what was left out, with the reason.

- **Goodreads** (CSV): books are matched to the library by title and author, ignoring case,
  accents, punctuation, subtitles and series notes; a title that fits two books is left out.
  Shelves become tags, and the `read` shelf marks a book finished on its “Date Read”. Books not in
  the library are only listed as left out (see [Decisions](../brief.md#decisions)).
- **AntennaPod** (database export, or OPML): the SQLite file opens in memory (expo-sqlite on
  Android, sql.js on the web); feeds are subscribed, played episodes marked and started ones get
  their place, matched by guid and then enclosure address. A newer Lelap place stays.
- **Smart AudioBook Player** (Android): the `position.sabp.dat` file in each played book folder is
  read with a small Java serialization reader and matched to the library file of the same name in
  the same folder.
