# M34 Importers

**Status:** in progress (from [`next.md`](../next.md)). Settings → Backup → "Import from another
app" opens a sheet with three sources. The parsers live in `packages/core/src/importers/` and apply
through the same functions the app uses (tags, finished marks, subscribe, saved places), stamped
with the import time so sync sends them on. Each import ends with a summary: how many items
matched and which were left out, with the reason. Phone checks are in
[`m34-follow-ups.md`](../m34-follow-ups.md).

- **Goodreads** (CSV from My Books → Import and export). Books are matched to the library by
  title and author, ignoring case, accents, punctuation, subtitles and series notes; a title that
  fits two books is left out rather than guessed. Shelves become tags (`to-read`,
  `currently-reading` and custom shelves); the `read` shelf marks the book finished on its "Date
  Read", so Stats counts it in the right year. **Decision:** books that are not in the library are
  listed as left out and nothing is added. Goodreads has no audio, and a list of Open Library works
  without a source would be an empty promise; looking them up through the Catalog add-on is a
  possible follow-up once "Want to read" (M30) exists.
- **AntennaPod** (database export, or its OPML). The SQLite file is opened in memory with
  expo-sqlite on Android and sql.js on the web. Subscribed feeds are fetched and subscribed;
  played episodes are marked finished on their completion date and started ones get their place,
  matched by guid and then enclosure address (the M5 episode keys). A place Lelap saved after
  AntennaPod last played the episode stays. Local-folder feeds and episodes no longer in their
  feed are reported.
- **Smart AudioBook Player** (Android). It keeps a `position.sabp.dat` in each book folder it has
  played: a Java-serialized `BookDataBackup` with the current file, the place in it (seconds), the
  last play (epoch ms) and the state (`Started`, `Finished`). Nothing to pick: the import lists
  the library folder, reads those files with a small Java serialization reader and matches each
  to the library file of the same name in the same folder. Finished books are marked on their
  last play; started ones get their place unless Lelap saved a newer one. Its bookmarks
  (`bookmarks.sabp.xml`) are not read yet: no sample file so far.

**Done when** a real Goodreads export, a real AntennaPod export and a Smart AudioBook Player library import on the phone with the
counts the listener expects, and the result reaches a second device through sync.
