# M109 Series and reading order

Several milestones already read series names and numbers from tags and catalogs. Start by listing
what exists (where a series is stored, how it is shown and synced), then build on it.

- **Reading order:** a series page lists its books by number, with fractional numbers (2.5) and
  books without a number placed sensibly; the listener can reorder it.
- **Next in the series:** when a book ends, offer the next one: play it if it is in the library,
  or open it in the catalog if an add-on has it.
- **Missing volumes:** show gaps in the numbering, so the listener sees which book they don't
  have.
- Series from catalogs and from tags should merge into one series when they match, using the
  work matcher from the SDK.
