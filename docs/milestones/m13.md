# M13 Landing page 2

The site's “Get it” section (`apps/site`) lists the Android channels (direct APK from the
downloads host, GitHub Releases, Obtainium, F-Droid later) with a SHA-256 note, in a “coming soon”
state until `PUBLIC_LELAP_RELEASED` is set. Sections fade in on scroll through a small inline
script; without JavaScript or with reduced motion nothing moves and nothing is hidden. Stable
releases also upload `latest.apk`, so the download button has a fixed address.
[#31](https://github.com/lelap-app/lelap/pull/31) dropped the “Screen off, still playing” badge.
