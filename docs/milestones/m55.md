# M55 Light landing page

**Status:** planned.

The landing page and developer docs follow the visitor's system setting: the current night theme
in dark mode, a light theme by day, with a switch in the header that remembers a choice. Colours
move to tokens so both themes come from one set of styles; Lori, the phone mock-up and the
screenshots get variants that read well on light backgrounds. The app keeps its night theme.

## Done when

- Every page of `lelap.app`, including `/docs`, reads well in both themes at desktop and phone
  width, with contrast that passes WCAG AA, and no flash of the wrong theme on load.
