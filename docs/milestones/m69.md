# M69 Casting 3

Casting work left out of M26, M45, M50, M51 and M58.

- Cast device authentication. (M26)
- Speaker groups across protocols. (M26)
- A receiver starts past a show’s intro, but the outro is not skipped there (M50 noted the same). (M45)
- Smart rewind is not tuned for receivers, which buffer a few seconds after a seek. (M50)
- `RemoteSession` timings (stale status 2.5 s, or 5 s after a load; stop as part end within 10 s) are reasoned, not measured; tune them on real receivers. (M50)
- While a receiver drops off without a word, its extrapolated place still counts until the lost link is noticed. (M51)
- Subsonic addresses have no extension, so receivers get `audio/mpeg` for any file and downloaded parts are named `.audio`; the extension is in the file’s path. (M58)
- Casting doesn’t put the Audiobookshelf key in the address. (M41)

Done when a podcast’s outro is skipped on a speaker and an Audiobookshelf book casts.
