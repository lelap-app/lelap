# M129 BookBrainz

[BookBrainz](https://bookbrainz.org/about) is MetaBrainz's open book database, the sister of
MusicBrainz. Its core data (works, editions, authors, series, their names in each language,
identifiers and relationships) is CC0; other public data is CC BY-SA
([BookBrainz licensing](https://bookbrainz.org/licensing)). This add-on asks it for what Open
Library and Wikidata lack. One of Lelap's own add-ons, off by default:
[Lelap's own add-ons](../brief.md#decisions) in the brief.

**Where it runs: on the catalog service**, like Whole series
(`services/catalog/src/bookbrainz/`, `/bookbrainz/manifest.json`, `app.lelap.bookbrainz`). It
needs no key and no account, every listener's question is the same, and one shared cache keeps the
load on MetaBrainz low.

## What the API offers

Checked on 2026-11-19 against `https://api.bookbrainz.org/1/`
([Swagger docs](https://api.bookbrainz.org/1/api-docs/),
[routes](https://github.com/metabrainz/bookbrainz-site/tree/65cccfc1c3f17db741dee0e58191bf1c6f77fc8e/src/api/routes)):

- No key, no sign-in, read only.
- `GET /search?q=…&type=work|edition|author|series` finds by name and by identifier value: `Q190192`
  (Wikidata) and `OL893427W` (Open Library) each found Dune's work.
- `GET /work/{bbid}`, `/aliases`, `/identifiers` (Open Library work IDs, Wikidata, ISBNs on
  editions) and `/relationships` (series, translations, authors).
- `GET /work?series={bbid}` lists a series' works, but neither it nor the series' relationships
  carry the position: Dune's series came back unnumbered.
- No published rate limit. MusicBrainz, on the same infrastructure, allows one request a second per
  IP on average ([MusicBrainz rate limiting](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting));
  the add-on keeps to that.

## Plan

- **Look-up by Open Library work.** For an `ol:` work: search BookBrainz by the work ID, then read
  the work's identifiers, names by language and series. Through `upstream.json`, so the Cache API
  on Workers and the memory cache in Docker keep each answer for a week, as Wikidata's are kept
  ([M127](m127.md)). One request at a time per instance, at most one a second, with a User-Agent
  that names Lelap and the operator's contact address from configuration.
- **Meta that adds to the Catalog's.** `fetchMeta` (`packages/core/src/addons/client.ts`) takes the
  first add-on that answers, so a second meta add-on for `ol:` works is never asked. Change it to
  take the first answer and fill what it lacks from the others: `externalIds` joined (adding
  `bb:` and `wikidata:`), titles by language, series, language. Fields the first answer has are
  never replaced.
- **Whole series where Wikidata has none.** A `series` resource that answers by series name and
  author. Since the API gives no positions, books are ordered by their first edition's date
  (`orderSeriesVolumes` already places books without a position). The series client
  (`fetchSeries`) asks the next add-on when one doesn't know a series, so Wikidata keeps priority.
  Also: offer MetaBrainz a pull request that adds the series position to `/work?series=`
  (the site's repository is open), and use it once deployed.
- **Only CC0 fields.** Names, identifiers, languages and relationships. Annotations and
  descriptions (CC BY-SA) are not used, so nothing needs a credit line; the item page links the
  BookBrainz work.
- **Offered, off by default.** `hostedAddons` in `apps/app/src/config.ts` lists add-ons that need
  the listener's account and open a configure page. Widen it for hosted add-ons that need neither:
  their offer under Lelap's own add-ons (`OwnAddons.tsx`) has Add, which installs the manifest
  straight away. Lepak ([M131](m131.md)) and Open lectures ([M132](m132.md)) use the same.
- **Tests.** Recorded answers for Dune and a series in `services/catalog/test/fixtures`, like
  `wikidata-answers.json`; a rate-limit test with a fake clock.

## Done when

- With BookBrainz added, a work that Open Library and Wikidata know only in English shows its
  BookBrainz titles in the listener's language, and its BookBrainz ID among its IDs.
- A series that Wikidata doesn't know but BookBrainz does lists on the series page.
- A burst of 20 look-ups reaches BookBrainz at most once a second; a repeat is served from the
  cache.
- An older app without the meta merge still works with the add-on installed.
