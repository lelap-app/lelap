# M36 Jellyfin

Jellyfin is a library source built into the app next to WebDAV and S3, not an add-on
(`packages/core/src/remote/jellyfin.ts`, `apps/app/src/jellyfin.ts`). It signs in with address,
username and password and keeps only the access token, sealed like other server secrets (M19).
Book and music libraries are scanned with chapters, people, covers and the user's place; items of
one album or folder become one book by the folder rules. Audio streams as the original file
(`/Audio/{id}/stream?static=true`, no transcoding), with the token as a header on Android and as
`api_key` in a browser.

Places go both ways: a scan takes the server's place and the newest change wins, and the app
reports start, pause, about every five minutes and the end of a book, for the profile that added
the server. Settings → Servers → Add a server → Jellyfin; in a browser the server must send CORS
headers. No migration: the server is a new kind in `library_roots.remote`.

## Open checks

- [ ] (you) **Sign-in and libraries.** On Jellyfin 10.9 or later and on 10.8: add the server, test the
      connection, check the Books library is picked and a music library can be added. Check that
      Jellyfin's Dashboard → Devices shows “Lelap” once, and that logging in again from Settings
      reuses that device instead of adding another.
- [ ] (you) **Books.** A library with single `.m4b` files (chapters shown), one with a folder of `.mp3`
      parts per book (one book, parts in order), and a music album. Check titles, authors and covers.
      A server behind a path (`https://host/jellyfin`) too.
- [ ] (you) **Playback.** Plays without transcoding (Dashboard → Activity shows Direct Play), seeks, and
      downloads with the header. On the web build: plays with `api_key` when the server allows the
      site; the CORS hint appears when it doesn't.
- [ ] (you) **Two-way progress.** Play in Lelap, pause, and check the Jellyfin web client resumes there;
      play further in the Jellyfin web client, rescan in Lelap, and check Lelap moves to that place.
      Finish a book in Lelap and check it shows played in Jellyfin. Check whether
      `/Sessions/Playing/Progress` updates the item's “last played” date: the merge compares that
      date with Lelap's own, so if it doesn't, Lelap's place wins until another client plays there.
- [ ] (you) **Casting.** A cast device can't send headers: casting a Jellyfin book may need `api_key` in
      the address instead. Check with Chromecast and a UPnP renderer.
