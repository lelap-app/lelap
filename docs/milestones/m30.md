# M30 Scrobbling

`scrobble` is a protocol resource: `POST /scrobble` takes a batch of events (start, progress,
pause, finish, abandon, rate), each with an `eventId` and its real time and never a source, stream
or file URL; catalogs may carry `shelf: "want-to-read"`. The app keeps events per add-on in
`scrobble_outbox` and sends them in order with backoff (`packages/core/src/scrobble.ts`,
`apps/app/src/scrobble.ts`); Home shows each want-to-read catalog as “Want to read”.

The Hardcover and gPodder add-ons live in `services/catalog/src/scrobble/`. Their settings are
sealed into the add-on URL with `CONFIG_SECRET` (AES-256-GCM), so nothing is stored. Docs:
`/docs/scrobbling/` on the site.
