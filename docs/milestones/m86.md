# M86 Sleep 2

- Shake to extend the sleep timer, as a setting.
- A bedtime routine: at a chosen time, the timer and a quieter volume start by themselves.
- “Where did I fall asleep?”: when playback stopped by the timer, offer to go back to the last
  place the listener was surely awake (before the fade, or the last interaction).

Done when a night with the routine ends faded, and the next morning offers the place before sleep.
