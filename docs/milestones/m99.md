# M99 Languages 3

What [M72](m72.md) left in English, or in the phone's language instead of the profile's.

- **Untitled chapters are saved empty** and named where they show: `setChapterNames` in
  `packages/core/src/library/chapterNames.ts`, set once by `apps/app/src/i18n/index.ts`, names
  them in `getBook` and `chapterTitleAt`, so the chapter list, the player, car mode, bookmarks,
  the notification, the widget and Android Auto all get “Chapter 3” or “Bab 3” in the language of
  the profile looking. Chapters found from silences are “Part 3”. Tags, podcast chapters files,
  Jellyfin, Audiobookshelf, the bundled Emby add-on and the edit screen all save an empty title;
  the edit screen shows the name as a placeholder, so saving unchanged still keeps the book's
  chapters. Migration `0027_chapter_names` empties the names saved before, in the chapters table,
  each file's chapters and the listener's own, but only where the number matches the chapter's
  place, in its file for a book of several files: a real “Chapter 7” in fourth place stays. The protocol says an add-on may leave a
  chapter's title empty ([brief](../brief.md), stream objects; the site's protocol page).
- **Media3's play and pause descriptions** follow the profile: `PlaybackService` builds its
  `DefaultMediaNotificationProvider` from `NativeText.localized(context)`, a context in the
  profile's language, and builds a new one and redraws the notification on a switch. Languages
  Media3 has no strings for show its English.
- **No raw native error text reaches the listener.** `Reasons.of(e, catalog)` in `modules/text`
  names the kind of failure (no answer, a timeout, an unknown address, a failed secure
  connection, a full disk, a folder whose access was withdrawn) or gives null; a `ShownException`
  carries a line already translated. Downloads use it in “The download kept failing: …” and the
  move's error, with SMB and SFTP failures through their own lines; the download folder's storage
  errors are translated where they are thrown (`Places.kt`, `Folders.kt`). The updater names its
  size check and PackageInstaller's status codes itself (`InstallFailure.kt`) instead of passing
  on Android's message. A UPnP fault shows its number only (“The speaker refused the command
  (UPnP error 714).”). The line under the player comes from Media3's error code
  (`PlayerErrors.kt`), and on the web from the `MediaError` code; diagnostics keep the codes.

An older version of the app on another device shows an untitled chapter synced from this one
(the listener's own chapters, a streamed book's) without a name until it updates. What is left
is in [M124](m124.md).
