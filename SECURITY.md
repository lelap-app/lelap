# Security

Please don't report security issues in public issues.

Use GitHub's **Report a vulnerability** button under this repository's Security tab. It opens a
private advisory that only maintainers can see. Include what you found, how to reproduce it, and
what an attacker could do with it.

We're especially interested in anything that could:

- let someone ship an app or OTA update that users would install,
- expose sync data or add-on URLs, which can contain tokens,
- turn the feed and cover proxy into a general proxy.

Lelap is early and run by volunteers. We'll acknowledge reports as soon as we can and credit you in
the advisory unless you'd rather stay anonymous.
